# Phase 5: Omni 导演脚本编译

## Omni 脚本的定位

Omni（或同类图生视频平台）支持「图文混排」的导演脚本格式：用自然语言描述每个片段的运镜、主体动作和过渡逻辑，并通过标注 `[图片N]` 引用对应的垫图帧。这种格式的优势是：

- 比纯 Prompt 提供更强的叙事连贯性控制
- 可以描述跨图片的过渡动作（如「同一面板开始翻转，切入图片2」）
- 支持多段落、有节拍的分段描述

## 5.1 格式结构

```
🟢 [项目名] · Omni 导演脚本 V[版本]

[一句话引导语，说明整体调性和目标]

---

**第N部分：[部分标题]（[图片X] → [图片Y]）**

[运镜 + 主体状态 + 初始画面描述]。[推进动作描述]。[cut到下一图片的触发条件]，切入 [图片Y]：[图片Y的画面状态 + 继续的动作]。[本段的结束状态]。

---

[重复每个部分...]

---

**制作要求：**

[材质要求] + [过渡要求] + [音效要求] + [帧率要求] + [画面比例]
```

## 5.2 运镜术语库

| 运镜类型 | 中文描述 | 配套描述词 |
|---|---|---|
| 推镜（Dolly in） | 镜头缓慢推近 / 匀速向前推近 | 速率：缓慢/中等/快速 |
| 拉镜（Dolly out） | 镜头拉远 / 爆炸式高速拉远 | — |
| 轨道平移（Orbit/Track） | 镜头贴着主体左/右轨道平移 | 配合「同时推近」 |
| 俯冲（Dive） | 镜头俯冲穿透 | 「穿透玻璃表面」 |
| 定焦静观（Lock-off） | 镜头保持不动，主体运动 | 给动效让出运动预算 |
| 螺旋推近（Helix push） | 缓慢顺时针/逆时针螺旋推近 | 展示立体结构细节时 |
| 正面推近（Front dolly） | 正面匀速推近 | 配合微距特写 |

## 5.3 物理质感描述词库

**毛玻璃类**：
- `薄如刀锋的深色毛玻璃面板`
- `磨砂粗糙度`、`半透明折射`
- `极细银色/白色 bevel 边缘高光随视角变化流动`
- `纸薄的玻璃截面一闪而过`

**厚玻璃类**：
- `带有物理厚度的玻璃砖`
- `浓厚的翠绿色绿边辉光`
- `边缘折射高光`

**卡片/小元素类**：
- `以弹性物理动力学依次弹出`
- `沿弧线轨迹飞向镜头`
- `有可见的玻璃厚度截面和边缘折射高光`
- `最近的图标在镜头前轻微离焦形成前景虚化`

**背景/环境类**：
- `纯黑虚空`
- `零重力深空`
- `悬在无重力的暗色影棚`

## 5.4 UI 动效描述规范

| 效果类型 | 描述模板 |
|---|---|
| 弹出效果 | `[元素] 从面板表面以弹性物理动力学依次弹出，沿弧线轨迹飞向镜头` |
| 卡片流入 | `[N]块与主面板同款的[材质]小卡片从画面[方向]以阶梯状[间隔]ms间隔依次飞入，在主面板[位置]堆叠成向[方向]延伸的3D层级序列` |
| 按钮点击 | `镜头完全[到达位置]，[按钮描述]被按下，[N]条同心圆涟漪从按钮中心以物理波动节奏向外扩散，每圈涟漪都带有[颜色]霓虹余晖` |
| 粒子解体 | `从左至右，[元素]依次产生蛛网状裂纹，从裂缝中迸发出[颜色]荧光粒子，粒子密度从左到右递增` |
| 失重漂浮 | `以不同的旋转速度和方向缓慢漂浮，其中[主面板描述]，周围的面板以不同角度展示侧面的[材质]截面` |

## 5.5 过渡连接描述模板

**核心原则**：过渡必须发生在「运动过程中」，而非「静止之后」。每个部分末尾必须有明确的物理出口动作。

**两类合法出口的写法**：

```
// 运动出口（推荐）
[效果动作]，随即 [出口动作——拉远/翻转/飞出]，
切入 [图片N]：[在运动状态中开始的新画面]。

// 黑帧出口
[主体高速飞出方向] 清空画面，最终以一帧黑色虚空收尾，
硬切 [图片N]：[新主体以运动状态出现]。
```

**需要注意的危险过渡**：效果完成后画面静止，然后直接引用下一图片。需要补一个出口：

```
// ❌ 危险写法（会跳切）
卡片飞入完成后形成阶梯排列，过渡到 [图片N]...

// ✅ 修复写法（加出口）
卡片飞入完成后形成阶梯排列，镜头随即向右快速推移穿过卡片群，
硬切 [图片N]：...
```

**完整过渡描述结构**：

```
[上一状态的结束动作]，
[出口动作（运动出口或黑帧出口）]，
切入 [图片N]：[下一帧的初始状态 + 继续的运动动作]。
```

## 5.6 制作要求模板

```
制作要求：
全程在任何特写和中景镜头中需凸显[材质类型]的真实材质表现：[材质关键词列表]；
任何画面切换都需要通过运镜自然过渡而非生硬跳切，在明暗交替节点精准卡点配合低频震动音效；
全程补帧保持流畅，禁止跳帧和闪烁；
画面比例[16:9/9:16/1:1]，广告级别视觉精度。
```

## 5.7 完整脚本示例（参考）

```
🟢 [项目名] · Omni 导演脚本

运用导演思维和专业的剪辑手法，按顺序组合这些镜头，生成一组专业的 [项目] 3D 动态宣传大片。

---

**第一部分：破空降临（[图片1] → [图片2]）**

镜头从纯黑虚空中缓慢推近，[图片1] 中一块[载体描述]悬浮在画面正中，[边缘高光描述]，[UI内容]在[表面描述]静静发光。镜头贴着[载体方向]缓慢轨道平移，同时柔和推近，凸显[材质特征]。推近至[比例]时，[载体]开始[退场动作]，切入 [图片2]：[图片2初始状态]，带有精准的运动模糊拖尾，最终以[结束状态]收尾。

---

[后续部分...]

---

制作要求：全程凸显[材质]表现；衔接自然不跳切；明暗节点配音效；补帧流畅；画面比例16:9，广告级别。
```

# Phase 1: 素材准备与风格锚定

## 1.1 UI 截图来源

**推荐方式：Stitch MCP**

使用 `mcp_stitch_get_screen` 或 `mcp_stitch_list_screens` 获取设计稿，再用 `view_file` 查看截图作为垫图素材。

Stitch 生成的截图优势：
- UI 内容完整、清晰
- 多屏幕可批量获取
- 无需启动本地开发服务

**备选：本地截图 / Figma 导出**

任何清晰的 UI 截图均可，分辨率建议 ≥ 1080px 宽。

## 1.2 风格锚定

风格锚定决定整个序列的视觉语言。**最可靠的方式是用一张已有的风格参考图**，而不是用文字描述。

找到一张你满意的、和目标风格匹配的现有图片（可以是：
- 之前生成过的、满意的图
- 行业参考/benchmark 截图
- 甚至是某个 UI showreel 的静帧

**关键原则**：风格参考图的每一个视觉特征都会被传递到后续所有帧：
- 载体形态（薄玻璃板 vs 厚玻璃砖 vs 手机模型 vs 悬浮卡片）
- 背景颜色（纯黑 vs 深灰 vs 渐变）
- 边缘处理（有/无 rim glow、bevel 高光颜色和粗细）
- 材质特征（磨砂、透明度、厚度感）

**常见踩坑**：
- 用文字描述风格而不用参考图 → 每帧模型理解不同，一致性差
- 风格参考图和 UI 截图混为一个输入 → 模型容易把 UI 当风格参考
- 风格参考图本身包含 effect（卡片飞入、粒子等）→ 建立帧会带入不需要的效果

## 1.3 素材清单

在开始生成前，确认以下素材已就绪：

| 素材 | 数量 | 说明 |
|---|---|---|
| UI 截图 | = 建立帧数量 | 每个 UI 屏幕一张 |
| 风格参考图 | 1张 | 锚定全局视觉语言 |
| 反面案例 | 0-1张 | 可选，告诉模型「不要这种」 |

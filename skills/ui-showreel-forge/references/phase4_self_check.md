# Phase 4: 自检与返工协议

## 核心原则

**每帧生成后立即目视检查，不合格立即返工，不要积累到最后才发现风格不一致。**

等所有帧都生成完再检查，代价是整个序列可能需要重做。边生成边检查，发现问题只需要重做 1-2 帧。

## 4.1 建立帧自检清单

生成建立帧后，对照以下维度逐一确认：

| 维度 | 检查内容 | 判断标准 |
|---|---|---|
| **载体形态** | 形状、圆角、比例是否与锚点帧一致 | 允许细微差异，不允许明显变形 |
| **背景颜色** | 纯黑 or 指定背景色是否一致 | 任何非预期颜色（灰、绿、白）= 返工 |
| **边缘处理** | rim glow / bevel 高光颜色和粗细 | 与锚点帧对比，不能突变 |
| **材质感** | 磨砂/透明度是否一致 | 与锚点帧对比 |
| **相机角度** | 倾斜角度是否与其他建立帧一致 | 偏差不超过约 10° |
| **UI 内容** | 正确的 UI 内容是否显示在载体上 | UI 文字、图标、颜色可识别 |
| **干净程度** | 是否有多余的 effect、飞出的元素 | 建立帧不允许有任何 effect |

**判断逻辑**：如果你把所有建立帧并排看，它们应该像「同一个设备的不同屏幕截图」，不是「不同的产品宣传图」。

## 4.2 效果帧自检清单

| 维度 | 检查内容 | 判断标准 |
|---|---|---|
| **载体一致性** | 与对应建立帧的载体是否完全一致 | 同一个物体，不允许形态改变 |
| **效果位置** | effect 是否从正确的位置产生 | 符合 UI 中元素的位置 |
| **效果风格** | 效果的材质/颜色是否与整体风格一致 | 效果物体的材质应与载体材质类似 |
| **背景** | 背景是否保持不变 | 不允许背景被 effect 改变 |

## 4.3 返工策略

**不要修改 Prompt 的全部内容**，先定位具体失败的维度，再针对性修改。

| 失败维度 | 修复操作 |
|---|---|
| 背景变色 | 在 Prompt 末尾加 `pure [color] background is mandatory, no other background` |
| 载体形态漂移 | 加强「与第一张参考图完全一致」的约束，将重要特征明确写出（如 `thin glass panel, no physical thickness, no rim glow`）|
| 带入不需要的 effect | 加 `NO effects, NO floating elements, NO exploded cards, static clean image` |
| UI 内容错误 | 检查是否传了正确的 UI 截图作为第二张垫图 |
| 风格整体偏离 | 说明是哪里偏，使用 Negative prompt 明确排除（如 `Negative: thick glass, green rim glow, warm background`）|

## 4.4 全序列最终检查

所有帧完成后，一次性连续浏览：

1. **风格连续性**：把所有建立帧并排，确认视觉语言一致
2. **过渡逻辑**：建立帧和对应效果帧之间，主体（载体）是否一致
3. **密度节奏**：建立帧（低密度）和效果帧（高密度）是否有明显的对比起伏
4. **谢幕效果**：F9（失重全景）和 F10（解体）的连续性

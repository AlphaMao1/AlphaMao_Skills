# Technology Mapping

从一个硬科技关键词出发，生成技术源流、学术谱系和商业化图谱。

硬科技投资里，真正难的不是列公司名单，而是看懂一条技术路线从哪里来、由哪些学者和实验室推动、哪些创业公司继承了这条路线、商业化分叉在哪里。这个 Skill 用 Agent 把这套 mapping 流程系统化。

## 适合

- VC / 投资人做硬科技赛道扫描
- 研究量子计算、核聚变、AI Agent、机器人、生物技术等前沿技术
- 梳理学术源头、师承链、创业团队和商业化路线
- 输出一张能解释领域结构的技术全景图

## 它会做什么

1. 分析领域特征，生成搜索策略和锚点
2. 发现全球公司、学者、实验室和里程碑
3. 追踪创始团队和学术师承关系
4. 按技术路线剪枝、聚类
5. 生成 Graphviz / SVG 图谱
6. 输出来源验证和文字报告

## 怎么触发

```text

帮我画一下这个赛道的技术全景图
研究一下这个硬科技方向的源流
做一张 technology map
```

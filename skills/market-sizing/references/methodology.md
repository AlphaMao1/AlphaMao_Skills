# 市场规模测算方法论

## 第一性原理

市场规模不是一个报告数字，而是一个市场定义下的经济活动量：

```text
市场规模 = 合格对象数量 x 采用/购买概率 x 使用/购买频次 x 单位价格或单位价值
```

所有方法都只是这个式子的变体。Top-down 从总市场往下切，Bottom-up 从对象和行为往上乘，替代法从原市场迁移，价值链法从终端价值拆分。

## TAM / SAM / SOM

- TAM：在定义边界内，理论上所有相关需求的规模。
- SAM：当前产品、渠道、地理、监管和能力可以服务的部分。
- SOM：在指定时间内，结合竞争、销售产能、进入节奏后可能拿到的部分。

TAM/SAM/SOM 默认是年度口径。预测期是 5 年时，应输出 2026E、2027E、2028E、2029E、2030E 每一年的 TAM/SAM/SOM，而不是把 5 年累计收入写成一个市场规模。只有在用户明确要求累计收入池时，才另列累计值，并和年度市场规模分开命名。

检查顺序：

```text
TAM >= SAM >= SOM
```

如果不成立，通常是口径混了：例如 TAM 是全球，SAM 是中国；或 SOM 是收入累计，SAM 是单年收入。

## 公式链纪律

每个关键数字只能来自三类：

| 类型 | 要求 |
|------|------|
| 引用 | 有 source card，保留原始口径和访问日期 |
| 计算 | 由已有输入通过公式推导，Excel 中能看到公式 |
| 假设 | 有类比、机制、约束、经验区间或反事实解释 |

不要用「低/中/高可信度」替代解释。更有用的是写清：

- 为什么用这个数据；
- 它和目标市场的口径差异；
- 做了什么换算；
- 如果它错 20%，影响哪个输出。

## 禁止裸假设

以下写法不合格：

```text
渗透率 = 5%
```

合格写法：

```text
甲市场 A/B 渗透率分别约 60%/40%；乙市场的购买方更重视低部署成本，产品 B 更匹配，但当前教育成本更高且面临 C 替代冲击。因此基准渗透率不取 40%，而取 20%，并在 Excel 中测试 10%/20%/30% 三档情景。
```

这仍然是估算，但它保留了判断链：类比市场、相似点、差异点、约束和情景。

## 常用计算架构

### Top-down

```text
TAM = 行业总规模 x 细分市场占比 x 地理/客群/渠道筛选
SAM = TAM x 可服务比例
SOM = SAM x 可获取份额
```

适合有行业总量或官方分类数据的市场。风险是报告口径常常比目标市场宽。

### Bottom-up

```text
TAM = 目标对象数 x 采用率 x 年频次 x 单价
```

适合能定义客户、用户、设备、门店、企业、项目等对象的市场。它通常更接近实际经营动作。

### Substitution

```text
TAM = 现有市场规模 x 可替代比例 x 价格/价值调整系数
```

适合新技术替代旧技术、软件替代人工、国产替代进口等。

### Value-chain

```text
TAM = 终端市场规模 x 目标环节价值占比 x 可服务比例
```

适合产业链环节、零部件、服务费、渠道费用等。

### Value-based

```text
TAM = 目标对象数 x 问题发生频率 x 单次成本/收益 x 愿付比例
```

适合新需求、新工具、新服务，还没有明确市场分类时。

## Side check

主模型完成后至少做一条 side check：

- 与竞品收入或分部收入相比。
- 与上游/下游市场规模相比。
- 与进口/出口/产量/装机量相比。
- 与相邻国家、成熟市场或相邻品类相比。
- 与客户预算、人均消费、企业 IT 支出等约束相比。

side check 不要求精确，但要能回答：这个结果是否在正确量级。

## Excel 承载要求

Excel 不是附件，而是模型本体：

- `核心结论` 必须是第一页，用一页展示逐年 TAM/SAM/SOM、TAM 构成、末年占比和一句话判断。
- `Assumptions` 只放可编辑输入。
- `Calculation_Model` 展示中间公式链。
- `TAM_SAM_SOM` 只引用公式结果，并按年度展示单年 TAM/SAM/SOM。
- `Checks` 显示单位、缺失 source、缺失 logic、TAM/SAM/SOM 层级等检查。

Markdown 中任何关键结论，都应能回到 Excel 的某个输入或公式单元。

如果 TAM 来自多个细分市场，第一页必须列出每个组成市场的年度规模，并检查组成项合计是否能对回总 TAM。不能只给“市场很大”或“5 年合计”这种不可复核的展示。

# 直觉泵

把《直觉泵》的 77 个思考工具变成一个可以被 Agent 路由、学习和调用的 Skill。

它适合处理难以说清、容易陷入直觉争论，或需要先找到合适思考路径的问题。Skill 会先识别问题形状，再推荐合适的工具；选定工具后，才读取对应的单张工具卡，把直觉变成可操作的对照、边界、反例、机制链或下一步验证。

## 适合

- 批评一个观点，但担心把对方说成稻草人
- 发现解释里藏着“聪明小人”“魔法步骤”或未经说明的跳步
- 拆开理解、意识、身份、自由、责任等容易混在一起的概念
- 检查“当然应该”“看起来像被设计过”等强烈直觉
- 在写作、研究、产品判断或复杂决策中找到可检查的思考路径
- 需要学习某个具体的 Dennett 式思想工具，而不是直接要一个结论

## 它会做什么

1. 识别当前问题主要属于论证、概念、解释、视角、进化、意识、自由责任或元认知中的哪一类。
2. 在不知道该用什么工具时，给出 5 个候选：1 个建议先用，4 个可选探索。
3. 每个可见工具都说明原书标题、名字在书里的背景，以及这个名字为什么对应当前动作。
4. 用户选定工具后，只读取对应的工具卡，再按卡片中的步骤应用。
5. 输出可被检查的改写、边界案例、反例、机制拆解、证据需求或下一步行动。

Skill 当前包含 77 张独立工具卡，覆盖《直觉泵》的八个部分。工具卡保留了原书背景，同时把思想实验转译为 Agent 可以执行的操作。

## 怎么触发

在支持 `SKILL.md` 的 Agent 中，可以这样说：

```text
帮我为这个问题推荐合适的思考工具
我想批评一个观点，但怕自己在打稻草人
这个解释里是不是藏着一个“聪明小人”
学习 003 拉波波特
用 010 小心当然检查这个产品判断
```

当你只想知道该用什么工具时，Skill 会先停在 5 个候选的路由菜单；当你明确点名某个工具时，会直接读取对应卡片；当你说“我卡住了”或“直接处理”时，会先给出菜单，再应用最适合的第一工具。

## 工具覆盖

| 工具层 | 主要问题 |
| --- | --- |
| 论证检验 | 前提、反驳、话术、强弱样本和隐藏证据 |
| 概念澄清 | 边界、二分、层级、表征和理解程度 |
| 解释生成 | 把看似聪明、神奇或整体性的现象拆成机制 |
| 视角切换 | 在常识映像、科学映像、意向立场和系统外视角之间切换 |
| 反直觉破局 | 用思想实验或反图像打断误导性直觉 |
| 进化机制 | 用选择、适应、信号、物种和文化复制解释设计感 |
| 意识拆解 | 僵尸、感受质、第一人称报告和身份问题 |
| 自由责任 | 决定论、选择、公平、历史事实和道德责任 |
| 元认知 | 判断问题是否值得做、如何读强者、如何校正自己的直觉 |

## 安装

在 Agent 中安装：

```text
帮我安装这个 skill：https://github.com/AlphaMao1/AlphaMao_Skills/tree/main/skills/intuition-pumps
```

如果手动复制，保持整个目录结构不变，至少需要保留：

## 使用边界

直觉泵是思考辅助工具，不是证据本身，也不替代事实核查、实验、测试或专业判断。它的作用是把一个模糊直觉变成可以比较、反驳和继续验证的对象；重要结论仍然需要回到实际材料和证据。

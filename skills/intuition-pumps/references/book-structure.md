# Book Structure

本文件记录原书结构，只作为分类、学习和补卡时的书内上下文参考。日常路由仍以 `tool-index.json`、`taxonomy.md` 和单张工具卡为准。

## 引言定位

原书把“直觉泵”当作一种能调动直觉的思想实验、故事、比喻或模型。它不是证明本身，而是把隐藏前提、变量旋钮、边界案例和反直觉后果显形，让人能更清楚地检查一个想法。

转成 skill 时，直觉泵必须落到可执行动作：

1. 说清它在泵动哪一种直觉。
2. 拆出可调变量或对照版本。
3. 产出可检查的改写、边界、反例、机制链或下一步验证。
4. 标明误用边界，避免把“我有一个强烈直觉”误当作结论。

## 使用规则

- 书内分组是第二分类层：它帮助理解来源和覆盖范围，不替代 `family`、`slots` 或当前问题类型。
- 学习模式解释某个工具时，如用户问“它在书里属于哪一类”，读取本文件即可，不要加载所有工具卡。
- 新增或重修工具卡时，身份区应填写 `原书分组`、`英文原名` 和 `中文标题来源`。
- `中文标题来源` 用来区分书内译名和 skill 为了操作性自拟的短命令。短命令可以短，但必须能被“名称与思想实验”解释回来。
- 前言、推荐序、译者后记、素材来源和参考文献不进入技能主流程；只在核对来源或用户明确询问时读取。
- 附录二的寄存器机练习题不默认转成通用练习层。只有当用户专门要学习计算机/算法相关工具时，才考虑作为局部练习素材。

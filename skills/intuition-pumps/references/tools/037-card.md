# 037 生命之树

## 身份

- 原书标题（中文）：生命之树：我们人类与谁有着共同的祖先
- 英文原名：The Tree of Life
- 中文标题来源：书内译名 + 书内副题。卡片标题“用共同祖先替代等级阶梯”是 skill 化后的功能副题。
- 原书分组：第五部分 关于进化论的思考工具
- 中文短命令：/生命之树
- 别名：37、工具37、生命之树、生命之树：用共同祖先替代等级阶梯
- 工具家族：进化机制
- 默认输出重量：中等。输出共同祖先、现存分支、灭绝分支、分化时间和错误阶梯改写。
- 对应 issue：ISSUE-046 / TOOL-037

## 名称与思想实验

“生命之树”让读者把进化史想象成一棵所有谱系都能追溯回生命起点的树，而不是一架从低级到高级的梯子。书中强调，现存基因组都能沿着父系、祖系和更古老的谱线向后追溯；人类彼此有共同祖先，人类与狗、鲸也有更古老的共同祖先，人类与植物的共同祖先则更古老。

这棵树的关键画法是：分支外缘代表现在，只有到达外缘的谱系才存活到今天。恐龙的许多分支已经灭绝，但鸟类作为相关后裔仍在树的边缘；如果把图放大到足够细，我们会看到曾经存在过的无数鱼、昆虫、蛙和其他个体谱线，其中大部分无后而终，少数延续到现在。

因此 `/生命之树` 要求使用者把“谁进化成谁”的线性问法改成“谁和谁在何处有共同祖先”。它不按高级/低级排序现存物种，而是追踪分支、灭绝、存活、分化时间和相似性的来源。

## 原书机制转译

这个工具处理“进化是从低级到高级、朝人类前进”的错误图像。生命史更像一棵不断分叉的树，而不是一架进步阶梯。现存物种都是树末端的幸存分支；亲缘远近来自共同祖先和分化时间，不来自谁看起来更“高级”。

`/生命之树` 的机制是把线性叙事改成分支图。不要说 A 进化成 B，而要问 A 和 B 的共同祖先在哪里、两条分支何时分开、哪些旁支已经灭绝、哪些相似性来自共同祖先，哪些来自趋同适应。

这张卡适合纠正“现代猴类进化成人”“某物种更高级”“外形像所以亲缘近”等常见误解。

## 用户模式

### 触发场景

- 有人把进化说成低级到高级、朝人类前进。
- 有人按相似外形直接判断亲缘关系。
- 你要解释多个物种的共同祖先和分支关系。
- 你需要把“谁变成谁”的说法改成“谁和谁有共同祖先”。

### 操作步骤

1. 列出要比较的物种或类群。
2. 找共同祖先，而不是把现存物种画成彼此祖先。
3. 标出现存分支和灭绝分支。
4. 用分化时间讨论亲缘远近。
5. 检查相似性来源：共同祖先、趋同适应、保留原始特征，还是人为分类习惯。
6. 删除高级/低级、进步/落后语言，改用分支、亲缘、适应和环境。
7. 给出一个小树图或分支表。


## 误用边界

- 不要说“猴子进化成人”。人和现代猴类是分支亲戚。
- 不要把旁支画成祖先。现存物种通常不是另一个现存物种的祖先。
- 不要用“高级/低级”替代具体适应和亲缘关系。
- 不要只凭外形判断亲缘。趋同适应会让远亲看起来相似。

## 小测试问题

请用 `/生命之树` 画一棵小树：人、狗、鲸、鸟、恐龙、植物，标出共同祖先而非进步线。

## 测试运行结果

比较对象：

人、狗、鲸、鸟、恐龙、植物。

错误阶梯说法：

植物 -> 恐龙 -> 鸟 -> 狗/鲸 -> 人。这个说法把演化误画成朝人类前进的等级线。

共同祖先分支：

```text
生命共同祖先
├─ 植物分支
└─ 动物分支
   ├─ 脊椎动物早期分支
   │  ├─ 哺乳动物分支
   │  │  ├─ 灵长类分支 -> 人
   │  │  └─ 其他哺乳动物分支
   │  │     ├─ 犬科方向 -> 狗
   │  │     └─ 鲸类方向 -> 鲸
   │  └─ 爬行动物/鸟类相关分支
   │     ├─ 非鸟恐龙分支 -> 已灭绝
   │     └─ 鸟类分支 -> 鸟
   └─ 其他动物分支
```

现存分支：

人、狗、鲸、鸟、植物都是现存分支的末端。

灭绝分支：

非鸟恐龙是灭绝分支。鸟类和某些恐龙类群有共同祖先，但现存鸟不是“从现代恐龙进步而来”；更准确是鸟属于恐龙相关演化分支中的现存后裔。

分化时间/亲缘远近：

狗和鲸都属于哺乳动物，亲缘关系比它们和鸟更近。人也属于哺乳动物。鸟与非鸟恐龙的关系近于鸟与哺乳动物的关系。植物和这些动物的共同祖先更古老。

相似性来源：

鲸和鱼外形相似不代表亲缘最近，可能来自水生环境下的趋同适应。狗和鲸外形差异大，但同属哺乳动物，亲缘上更近。

改写后的说法：

这些生物不是排成一条从低级到高级的线，而是来自共同祖先后不断分叉的生命树。亲缘远近要看共同祖先和分化时间，不看谁更像人或谁更“高级”。

测试结论：通过。本工具把进化阶梯改成共同祖先分支图，并标出了现存分支、灭绝分支和亲缘判断依据。

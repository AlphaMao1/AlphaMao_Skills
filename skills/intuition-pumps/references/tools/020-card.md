# 020 小人委员会

## 身份

- 原书分组：第二部分 关于意义和内容的思考工具
- 中文短命令：/小人委员会
- 别名：20、工具20、大脑中的小人儿委员会、大脑中的小人儿委员会：用很多笨组件替代一个聪明小人
- 工具家族：解释生成
- 默认输出重量：中等到较重。输出可疑小人、任务清单、笨组件拆解、协调机制和剩余黑箱。
- 对应 issue：ISSUE-029 / TOOL-020

## 名称与思想实验

“小人委员会”来自一个常见坏解释：我们把一个复杂能力塞进脑内某个“小人”或中央观察者，好像里面有人看懂画面、理解意义、做出决定。问题是，这个小人如果也需要看、懂、决定，那它里面是不是还要有更小的小人？这会把原问题无限搬下去。

“委员会”这个词的重点是替换：不要找一个全能小人，而是把任务分给很多更笨、更局部的组件。每个组件只做一点简单工作，整体效果由它们的协调产生。

## 原书机制转译

这个工具处理解释里的“小人儿”。当你说大脑里有一个观察者、中央控制者、理解模块或灵魂驾驶员时，往往只是把原问题搬进了系统内部：如果内部小人能看、懂、决定，那小人里面是否还需要另一个小人？这会导致无限倒退。

`/小人委员会` 的机制是把一个聪明小人替换成许多较笨、较局部、无需完整理解的组件。每个组件只做简单任务：检测特征、比较差异、匹配记忆、竞争、抑制、加权、触发输出。解释的目标不是找到一个更小的“真正理解者”，而是让整体智能从许多不智能的步骤组合出来。

小人儿可以作为临时标签，但不能成为最终解释。只要某个内部模块仍被要求“看懂全部”“判断意义”“作出最终决定”，就还没有拆完。

## 用户模式

### 触发场景

- 解释中出现内部观察者、中央控制者、灵魂驾驶员或“负责理解的模块”。
- 你说“系统识别了/理解了/决定了”，但中间机制仍是黑箱。
- 你想把一个聪明任务拆成可实现的子任务。
- agent 解释里出现魔法步骤：某模块突然知道了答案。

### 操作步骤

1. 找出解释里最聪明的小人儿或魔法模块。
2. 列出这个小人被要求完成的任务。
3. 把任务拆成更小功能：感知、特征提取、比较、记忆匹配、竞争、抑制、阈值判断、输出。
4. 检查每个子功能是否还需要完整理解；需要的话继续拆。
5. 写出组件如何协调：顺序、并行、反馈、竞争、投票或阈值。
6. 标出仍未解释的黑箱，避免假装已经完成。
7. 形成一个“无中央小人”的机制草图。

### 输出结构

```text
原解释：
可疑小人/魔法模块：
它被要求完成的任务：

笨组件拆解：
1.
2.

协调机制：
仍未拆开的黑箱：
改写后的解释：
```

## agent 自救模式

### 卡住信号

- 我写出“模块理解/观察/决定”，但没有说明模块怎么做到。
- 我把问题搬进系统内部，没有降低解释难度。
- 解释中存在一个能直接读意义、懂全部上下文、做最终裁决的角色。
- 用户如果追问“它怎么知道”，我只能重复原词。

### 自救动作

1. 圈出最聪明的内部词。
2. 列它承担的全部任务。
3. 把任务拆成无需理解的微操作。
4. 给出组件之间的协调方式。
5. 如果还有黑箱，明确标注，不把它包装成解释。

### 轻量输出

```text
工具：/小人委员会
当前卡点：解释里可能藏着一个聪明小人。
本工具给出的拆分：魔法模块 / 子任务 / 笨组件 / 协调方式 / 剩余黑箱。
下一步：用多个局部机制替代一个全能内部观察者。
```

## 误用边界

- 可以用小人儿做临时标签，但必须标注为占位符，并继续拆解。
- 不要把一个聪明小人换成五个同样聪明的小人。每个组件都要更笨、更局部。
- 不要假装所有黑箱都拆完。复杂系统可以保留待研究部分，但要诚实标出。
- 不要把“没有中央小人”误解成“没有协调”。协调机制仍然需要说明。

## 小测试问题

请用 `/小人委员会` 把“我认出朋友”拆成视觉特征、记忆匹配、情绪熟悉感、命名、行动反应。

## 测试运行结果

原解释：

我认出朋友，是因为大脑里的识别模块看出这是朋友。

可疑小人/魔法模块：

“识别模块看出这是朋友”。这个模块被赋予了看见、比较、理解身份和给出结论的完整能力。

它被要求完成的任务：

- 提取脸部和身体特征。
- 和记忆中的人物表征比较。
- 判断熟悉感。
- 找到名字和关系。
- 触发打招呼、微笑或靠近等行动。

笨组件拆解：

1. 视觉特征提取：检测轮廓、脸型、眼鼻嘴位置、步态、衣着等线索。
2. 特征稳定化：在光线、角度、遮挡变化下保留相对稳定的特征。
3. 记忆匹配：把当前特征和已存的人物模式做相似度匹配。
4. 熟悉感信号：当匹配强度超过阈值时产生“熟悉”的情绪或身体反应。
5. 身份候选竞争：多个相似人物候选竞争，最强候选被暂时选出。
6. 命名关联：把身份候选和姓名、共同经历、关系角色连接起来。
7. 行动反应：根据关系和情境选择微笑、打招呼、靠近或保持距离。

协调机制：

视觉线索先触发多个候选，记忆匹配和熟悉感并行增强某些候选；身份候选竞争后，命名和行动系统接入。若匹配不稳定，系统会继续观察或发问确认。

仍未拆开的黑箱：

具体神经实现、记忆编码方式、熟悉感如何和候选竞争耦合，这些仍需要更细机制。

改写后的解释：

我认出朋友，不是因为脑内有一个小人直接看懂了“这是朋友”，而是因为视觉特征提取、记忆匹配、熟悉感信号、身份候选竞争、命名关联和行动选择共同形成了识别结果。

测试结论：通过。本工具把一个聪明识别小人拆成多个较笨组件，并保留了协调机制和剩余黑箱。

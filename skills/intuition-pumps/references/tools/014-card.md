# 014 观念网络

## 身份

- 原书标题（中文）：生活在克利夫兰的一位兄长：一种观念只能生长在一堆观念之上
- 英文原名：An Older Brother Living in Cleveland
- 中文标题来源：书内译名 + 自拟功能副题。短命令“观念网络”和卡片标题“一个观念需要一堆观念托住”是 skill 化后的操作性改写。
- 原书分组：第二部分 关于意义和内容的思考工具
- 中文短命令：/观念网络
- 别名：14、工具14、生活在克利夫兰的一位兄长、生活在克利夫兰的一位兄长：一个观念需要一堆观念托住
- 工具家族：概念澄清
- 默认输出重量：中等。输出目标信念、支撑概念、推理关系、反事实区分和理解判定。
- 对应 issue：ISSUE-023 / TOOL-014

## 名称与思想实验

“生活在克利夫兰的一位兄长”来自一个脑内植入信念的思想实验。丹尼特设想未来有一种认知微神经外科技术，可以把一个命题直接写进人的大脑。现在医生试图给汤姆植入一个错误信念：他有一个哥哥住在克利夫兰。

如果这个信念只是孤立地出现，汤姆一被追问哥哥叫什么、自己是否独子、哥哥住在哪里，就会立刻露馅。要么他的正常理性系统把这个植入物排斥掉，要么他开始表现出病理性的混乱和虚构。关键点是：能说出一句话不等于拥有那个观念；真正的观念必须和亲属、地点、居住、身份、时间、反事实等一整套概念网络接上。

所以这张卡的短命令叫“观念网络”。它把“X 知道 P”拆成更严格的问题：X 是否拥有支撑 P 的相关概念、区分能力和推理后果？如果没有，它可能只是复述了一句话，或者触发了一个标签，而不是掌握了一个完整观念。

## 原书机制转译

这个工具反对把观念想成一颗可以单独植入的珠子。一个信念如果真有内容，就必须嵌在一张概念网络里：它依赖相关词义、分类、时间持续、空间关系、身份关系、因果关系和可推理后果。孤立的一句话即使被准确复述，也未必构成拥有这个观念。

`/观念网络` 的机制是把一句“X 知道 P”改写成“X 是否拥有支撑 P 的概念网络”。它不只检查 X 是否说得出 P，还检查 X 能不能区分相近情况、回答合理追问、把 P 放进其他信念中推理，并在语境变化时保持内容稳定。

这个工具适合评估人、孩子、动物、模型、组织或系统是否真的掌握某个信念。它的目的不是设置过高门槛，而是把“复述句子”“局部标签能力”“完整观念”分开。

## 用户模式

### 触发场景

- 你看到“植入一个信念”“某人只相信一句话”“模型知道某事实”等说法。
- 你需要判断一个人、模型或系统是在理解、背诵、匹配标签，还是只做局部反应。
- 你要把一个概念解释给外行，想知道它至少依赖哪些前置概念。
- 争论里有人把能说出一句话当成拥有完整观念。

### 操作步骤

1. 把目标信念写成一句明确的话。
2. 拆出这句话至少需要的 8-12 个支撑概念。
3. 为每个支撑概念写一个最低掌握标准：主体必须能区分什么、不能只重复什么词。
4. 列出目标信念会带来的 3-5 个推理后果。
5. 列出 2-3 个容易混淆的相邻说法，检查主体能否区分。
6. 检查主体实际具备哪些概念和推理能力。
7. 给出判定：完整观念、局部观念、复述、标签匹配，或无法判断。

### 输出结构

```text
目标信念：

支撑概念：
1.
2.

推理后果：
-

相邻混淆项：
-

缺口：
判定：完整观念 / 局部观念 / 复述 / 标签匹配 / 无法判断
下一步验证问题：
```

## agent 自救模式

### 卡住信号

- 我写“用户/模型/系统知道 X”，但证据只是它说出过 X。
- 我把一个复杂概念当成无需前置条件的原子词。
- 我在解释一个概念时越讲越绕，因为没有拆出支撑概念。
- 当前方案依赖某个“大家都懂”的观念，但这个观念可能并不共享。

### 自救动作

1. 抽出我声称对方知道或理解的那句话。
2. 写出支撑这句话的概念网络。
3. 把每个概念转成一个最低区分能力。
4. 检查已有证据支持哪些能力。
5. 把结论降级为完整观念、局部观念、复述或标签匹配。
6. 如果需要继续验证，生成 2-3 个能区分理解与复述的问题。

### 轻量输出

```text
工具：/观念网络
当前卡点：我可能把能说出一句话当成拥有一个观念。
本工具给出的拆分：目标信念 / 支撑概念 / 推理后果 / 相邻混淆项。
下一步：按证据把“知道”降级或确认，并补验证问题。
```

## 误用边界

- 不要把概念网络要求提高到只有专家才算理解。日常理解可以是粗粒度的。
- 不要把不会解释每个前置概念等同于没有观念。很多能力可以通过使用和区分体现。
- 不要只列概念清单。关键是看这些概念是否能支持推理、区分和纠错。
- 不要用这个工具武断否定模型或儿童。它应该给出分层判定，而不是二分裁决。

## 小测试问题

请用 `/观念网络` 检查这句话：“X 知道他哥哥住在克利夫兰。”列出至少 10 个隐含概念，并判断一个只能复述这句话的系统是否拥有这个观念。

## 测试运行结果

目标信念：

X 知道他哥哥住在克利夫兰。

支撑概念：

1. X：能区分这个主体和其他主体。
2. 知道：能区分知道、猜测、听说、误信和不知道。
3. 他：能识别代词指向 X，而不是其他男性。
4. 哥哥：能理解亲属关系、性别、同父母或家庭关系、比 X 年长。
5. 住在：能理解居住不是短暂停留、旅游或曾经到过。
6. 克利夫兰：能把它当作一个地点或城市，而不是人名或物品。
7. 地理位置：能理解一个人可以位于或居住在某个城市。
8. 持续性：能理解居住状态会持续一段时间，也可能改变。
9. 身份保持：能理解哥哥换城市后仍是同一个哥哥。
10. 信息来源：能区分 X 是亲眼知道、被告知、推断，还是被误导。
11. 事实状态：能理解“住在克利夫兰”可以为真或为假。
12. 关系推理：能推出如果哥哥搬到芝加哥，原句可能不再为真。

推理后果：

- 如果有人问 X 的哥哥在哪里，X 应该能回答克利夫兰。
- 如果哥哥只是去克利夫兰出差，原句不一定成立。
- 如果 X 没有哥哥，原句的前提会失败。
- 如果 X 只听过这句话但不理解“哥哥”或“住在”，最多是复述。

相邻混淆项：

- “X 的哥哥去过克利夫兰”不等于“住在克利夫兰”。
- “X 住在克利夫兰”不等于“X 的哥哥住在克利夫兰”。
- “X 听说哥哥住在克利夫兰”不等于“X 知道哥哥住在克利夫兰”。

主体能力证据：

如果这个系统只能逐字复述“X 知道他哥哥住在克利夫兰”，没有能力回答“哥哥是谁”“住在和去过有什么不同”“如果哥哥搬家了怎么办”，那么证据只支持它保存或输出了句子。

缺口：

缺少亲属关系、地点、居住状态、知道与听说的区别，以及反事实更新能力的证据。

判定：

复述。它拥有的是一句可输出文本，不是完整观念。若它能回答部分追问，可升级为局部观念；若能稳定处理相关区分和推理，才接近完整观念。

下一步验证问题：

1. X 的哥哥如果只在克利夫兰住酒店一晚，还算住在克利夫兰吗？
2. 如果 X 的哥哥搬到芝加哥，原句还成立吗？
3. X 知道这件事和 X 听别人说过这件事有什么区别？

测试结论：通过。本工具把一句孤立信念拆成概念网络、推理后果和相邻混淆项，避免了把复述误判为完整观念。

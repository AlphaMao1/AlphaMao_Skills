# 069 无效历史

## 身份

- 原书标题（中文）：无效历史事实：用强行分类抹平微小差异
- 英文原名：Inert Historical Facts
- 中文标题来源：书内译名 + 书内副题。卡片标题“别让无痕差异承担解释”是 skill 化后的功能副题。
- 原书分组：第七部分 关于自由意志的思考工具
- 中文短命令：/无效历史
- 别名：69、工具69、无效历史事实、无效历史事实：别让无痕差异承担解释
- 工具家族：自由责任
- 默认输出重量：中等。输出过去事实、当前痕迹、预测差异、行动差异和解释权重。
- 对应 issue：ISSUE-078 / TOOL-069

## 名称与思想实验

“无效历史事实”指那些也许在逻辑上有真相、但在当前世界没有留下可用痕迹的过去差异。丹尼特最喜欢的例子是：我牙齿里的某些金子是否曾经属于凯撒。除非有极端完整的来源记录、博物馆戒指、熔化录像等证据，否则我们几乎永远无法知道；即便量子层面的粒子身份问题也会让追踪更困难。无论真相是哪一个，它都可能不再影响当前判断。

原书随后用数字化解释这种“无效”。假设同一首歌刻录到两张无标签 CD，夜里随机选一张复制到电脑，再消除指纹和痕迹。电脑里的歌究竟来自 A 盘还是 B 盘，可能有一个历史答案；但数字拷贝会把无关的微观差异通过标准化抹掉，只保留 0 和 1。只要比特完全相同，听觉、文件内容、后续复制都无法携带“来自哪张盘”的个性。

短命令 `/无效历史` 因此要求把事实真伪和解释有效性分开。一个过去事实可能是真的，却没有当前痕迹、预测差异或行动差异。它不该被拿来承担解释、责任或决策的核心工作。只有当过去事实通过记录、记忆、制度、因果痕迹或风险进入当前问题时，它才重新获得权重。

## 原书机制转译

这个工具处理“争论依赖一个过去差异，但这个差异没有留下任何当前可用痕迹”的问题。某些过去事实即便曾经存在，如果它们不影响当前证据、不改变预测、不改变行动选择，就不应该在当前解释中承担核心工作。

`/无效历史` 的机制是对一个历史事实做三问：它留下了什么痕迹？它改变了什么预测？它影响了什么行动？如果三者都没有，那个过去差异可能是真实的，但对当前解释无效。

这个工具不是否认过去，而是限制无痕过去的解释权重。过去事实要发挥解释作用，通常需要通过痕迹、因果影响、制度记录、记忆、证据链或行动后果进入当前问题。

## 用户模式

### 触发场景

- 争论依赖一个过去差异，但这个差异没有留下任何当前可用痕迹。
- 有人说“关键在于它以前是不是这样”，但无法说明当前差别。
- 你需要判断一个历史事实是否真的影响当前证据、预测或行动。
- 一个概念争论靠不可检测的过去差异维持。

### 操作步骤

1. 写出被引用的过去事实。
2. 写出当前问题：解释、预测、责任、身份、价值还是行动选择。
3. 问这个过去事实留下了哪些痕迹：物理痕迹、记录、记忆、制度状态、行为后果。
4. 问它改变哪项当前证据或预测。
5. 问它改变哪项当前行动：选择、责任、信任、风险、修复、制度处理。
6. 如果有痕迹或行动差异，保留它并说明影响路径。
7. 如果没有痕迹、没有预测差异、没有行动差异，把它从核心解释中移除。
8. 区分“事实可能为真”和“事实对当前解释有效”。

## agent 自救模式

### 卡住信号

- 我让一个无法留下差异的过去事实承担解释。
- 我没有说明过去事实如何影响当前证据。
- 我把“曾经发生过”直接当成“现在有解释力”。
- 当前判断即使移除这个过去事实也不变。
- 我混淆了事实真伪和解释有效性。

## 误用边界

- 不是否认过去，而是限制无痕过去在解释中的权重。
- 如果过去事实影响信任、责任、法律、来源、身份或制度记录，就可能不是无效历史。
- 不要把“当前无法检测”直接等同于“永远无效”；新证据可能改变权重。
- 不要用这个工具抹掉创伤、承诺、来源或因果链；这些常常留下心理、社会或制度痕迹。
- 如果当前问题本来就是历史真相本身，过去事实当然是核心对象。

## 小测试问题

请用 `/无效历史` 比较“随机数表是昨天生成还是十年前生成”：如果序列和使用方式一样，差别何在？

## 测试运行结果

过去事实主张：

同一张随机数表，序列完全相同，使用方式完全相同。版本 A 是昨天生成的，版本 B 是十年前生成的。

当前问题：

这张随机数表能否用于今天的抽样任务。

| 检查项 | 是否有差异 | 说明 |
| --- | --- | --- |
| 当前痕迹 | 无差异 | 两张表的数字序列、文件内容、可读性完全一样 |
| 证据/预测 | 无差异 | 用同一序列执行同一抽样，会得到同样结果 |
| 行动选择 | 无差异 | 如果只关心抽样结果，使用哪一张不改变行动 |
| 制度/责任影响 | 视情境而定 | 若审计要求使用今日新生成随机数，则生成时间会通过制度规则产生差异；否则无差异 |

是否保留为核心解释：

如果当前问题只是“这串数字会产生什么抽样结果”，生成时间不应保留为核心解释。数字序列和使用方式已经决定结果。

如果移除，当前判断是否变化：

在无审计、无承诺、无安全要求的场景中，移除“昨天还是十年前生成”后，当前抽样判断不变。

结论：

“昨天生成”与“十年前生成”可能是不同历史事实，但如果没有留下可用痕迹，也不改变预测或行动，它对当前抽样解释无效。若制度要求新鲜随机数、要求防泄露或要求审计记录，生成时间才重新获得解释权重。

测试结论：通过。本工具排除了没有留下差异的历史事实解释，同时保留了制度和审计场景中的例外。

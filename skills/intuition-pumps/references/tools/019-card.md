# 019 层级归因

## 身份

- 原书标题（中文）：人与“次人”的区别：自上而下的认知能力分解
- 英文原名：The Personal/Subpersonal Distinction
- 中文标题来源：书内译名 + 书内副题。卡片标题“把能力归到正确层级”是 skill 化后的功能副题。
- 原书分组：第二部分 关于意义和内容的思考工具
- 中文短命令：/层级归因
- 别名：19、工具19、人与次人的区别、人与“次人”的区别：把能力归到正确层级
- 工具家族：概念澄清
- 默认输出重量：中等。输出层级表、谓词适配判断、改写版本和低层支撑关系。
- 对应 issue：ISSUE-028 / TOOL-019

## 名称与思想实验

“人与次人”的意思不是价值高低，而是层级差别：人这个整体行动者能相信、决定、负责；大脑、眼睛、神经元、基因这些“次人”结构能支撑这些能力，但通常不能字面承担同一个谓词。说“我的大脑决定了”可以是简写，但如果把责任、承诺或信念直接丢给低层部件，就会混淆解释层级。

所以 `/层级归因` 的名字指向一个动作：把“谁在看、谁在信、谁在决定、谁负责”放回能承担它的正确层级，同时说明低层结构怎样支撑高层能力。

## 原书机制转译

这个工具处理层级混杂的归因错误。很多词只适用于整体行动者：相信、决定、负责、看见、想要、承诺。但整体行动者的能力又确实由大脑、神经系统、细胞、基因、组织流程等低层结构实现。解释时既不能把整体神秘化，也不能把局部组件直接说成小人。

`/层级归因` 的机制是先确定你正在使用的谓词，再判断哪个层级能真正承担这个谓词。若谓词不适配当前层级，就把它上移或下移：整体行动者层说“我决定吃蛋糕”，神经系统层说“奖赏和控制系统参与选择”，细胞/化学层说“多巴胺、血糖、激素等改变状态”。低层支撑高层，但不直接替代高层。

这个工具能清理“眼睛看见”“大脑相信”“基因想要”“公司决定”等表达。它不会禁止隐喻，但会要求你知道自己是在简写、比喻、机制说明，还是责任归因。

## 用户模式

### 触发场景

- 你看到“眼睛看见”“大脑相信”“基因想要”“公司决定”等层级混杂表达。
- 你要判断责任、意图、信念、选择或能力应该归给哪个层级。
- 你在写机制解释，但不想把低层组件拟人化。
- 你在做还原解释，但不想把整体行动者层面的事实抹掉。

### 操作步骤

1. 摘出可疑句子。
2. 标出核心谓词：看见、相信、想要、决定、负责、优化、承诺等。
3. 列出可能层级：整体行动者、组织/角色、器官/系统、子系统、细胞/化学、物理过程。
4. 判断每个层级能否承担该谓词：能、只能隐喻、只能支撑、不能承担。
5. 把句子改写成至少两层：高层行动者描述和低层机制描述。
6. 说明低层如何支撑高层，而不是直接取代高层。
7. 如果涉及责任或评价，明确责任归因停在哪个层级。

| --- | --- | --- |

## agent 自救模式

### 卡住信号

- 我把“模型想要”“大脑决定”“市场相信”写成事实，但没说明层级。
- 我用低层机制直接取消了高层解释。
- 我让局部组件承担了整体行动者的责任。
- 当前表达听起来聪明，但实际混淆了机制、行为和责任。

### 自救动作

1. 抽出可疑谓词。
2. 写出可能层级。
3. 判断该谓词在哪个层级是字面、在哪个层级只是简写。
4. 改写成高层行为句和低层机制句。
5. 若涉及责任，明确责任不能落在局部组件上。

### 轻量输出

```text
工具：/层级归因
当前卡点：我可能让错误层级承担了错误谓词。
本工具给出的拆分：整体行动者 / 子系统 / 机制组件 / 物理过程。
下一步：把谓词放回能承担它的层级，并说明低层支撑关系。
```

## 误用边界

- 不要把局部组件拟人化到承担整个行动者的责任。
- 不要用低层机制直接取消高层行动者层面的真实模式。
- 不要把所有日常简写都判成错误。很多表达可用，但要知道它是简写。
- 不要忽略组织层。公司、团队、系统有时可以在制度和流程意义上承担决策谓词。

## 小测试问题

请用 `/层级归因` 把“我的大脑决定吃蛋糕”改写成三层描述：人层、神经系统层、细胞/化学层。

## 测试运行结果

原句：

我的大脑决定吃蛋糕。

核心谓词：

决定、吃蛋糕。

| 层级 | 能否承担谓词 | 更准确表述 |
| --- | --- | --- |
| 人层 | 能承担“决定”和“吃蛋糕” | 我决定吃蛋糕，并采取行动去吃 |
| 神经系统层 | 不能字面承担责任性“决定”，但能说明选择机制 | 奖赏系统、记忆、饥饿信号和控制系统共同影响了这个选择 |
| 细胞/化学层 | 不能承担“决定”，只能说明底层状态变化 | 多巴胺、血糖、激素、神经递质和细胞活动改变了相关神经回路状态 |

高层表述：

我在看到蛋糕、感到想吃并权衡之后，决定吃蛋糕。

低层机制表述：

这个决定由神经系统中与奖赏、记忆、饥饿、抑制控制相关的过程实现，并受到一系列细胞和化学状态影响。

支撑关系：

神经系统和细胞/化学过程支撑了人的选择能力，但它们不是独立的小行动者。说“大脑决定”可以作简写，但严格说，决定属于人这一整体行动者层级。

责任/评价归因：

如果讨论健康选择、习惯或责任，责任通常归在人层，而不是归给“大脑”或“多巴胺”。低层机制可以解释诱因和限制，但不能自动替代责任判断。

结论：

更准确的三层描述是：我决定吃蛋糕；我的神经系统实现并影响了这个选择；细胞和化学过程构成这些神经活动的底层条件。

测试结论：通过。本工具把一个层级混杂句改写为人层、神经系统层和细胞/化学层，保留低层机制而没有让局部组件承担整体行动者的谓词。

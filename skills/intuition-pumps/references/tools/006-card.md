# 006 奥卡姆扫把

## 身份

- 原书标题（中文）：奥卡姆扫把：有意隐瞒对自己不利的证据
- 英文原名：Occam's Broom
- 中文标题来源：书内译名 + 自拟功能副题。卡片标题“检查自己有没有藏起坏证据”是 skill 化后的操作性改写。
- 原书分组：第一部分 通用思考工具
- 中文短命令：/奥卡姆扫把
- 别名：06、工具06、奥卡姆扫把、奥卡姆扫把：检查自己有没有藏起坏证据
- 工具家族：论证检验
- 默认输出重量：中等。输出最不利证据段、被省略证据、结论受影响方式。
- 对应 issue：ISSUE-015 / TOOL-006

## 名称与思想实验

“奥卡姆扫把”是分子生物学家西德尼·布伦纳对“奥卡姆剃刀”的反讽改造。剃刀是剃掉不必要实体；扫把则是把对自己不利的事实扫到地毯下面。这个名字本身就带着警告：它不是一件好工具，而是一种需要识别和抵抗的坏习惯。

原书把它称为“反思想”工具，因为它让理论表面上变得干净，实际上却靠隐藏麻烦事实来维持说服力。丹尼特借福尔摩斯故事里的“夜里没有叫的狗”说明这种危险：外行常常只看见摆出来的证据，专家才更容易注意到哪些关键事实不在现场。

所以“扫把”的画面是：作者没有正面反驳坏证据，而是把它们从读者视野里扫走。使用这张卡时，动作正好反过来：主动找回那些缺席事实，尤其是自己最不想写进论证里的反例、失败案例、专家异议和边界条件。

## 原书机制转译

奥卡姆扫把不是一个应该使用的好工具，而是一个要识别和反制的坏习惯：把不利事实、反例、失败案例或麻烦变量扫到地毯下面，让理论表面变得干净。它的问题在于，论证看起来更顺了，但真实承压能力变弱了。

作为 skill 命令时，`/奥卡姆扫把` 的作用是主动寻找被省略的坏证据，尤其是自己最不想写进方案、文章或解释里的部分。它要求把这些证据补回论证，然后观察结论是只需限定、明显变弱，还是直接崩塌。

## 用户模式

### 触发场景

- 一个理论或方案讲得很漂亮，但你隐约觉得它避开了不利事实。
- 你正在写自己的方案，需要做反方审查。
- 论证过于整洁，没有处理失败案例、边界条件或反例。
- 你怀疑作者只展示支持证据，跳过了麻烦证据。

### 操作步骤

1. 写出当前理论或方案最核心的结论。
2. 问：这个结论最怕哪三类事实？
3. 搜索或回忆作者是否处理过这些事实。
4. 写一个“最不利证据段”，替反方攻击自己。
5. 把这些证据补回论证。
6. 判断结论变化：保持、需要限定、显著变弱、直接崩塌。

### 输出结构

```text
当前结论：

它最怕的事实：
1.
2.
3.

最不利证据段：

补回证据后的结论变化：
保持 / 需要限定 / 显著变弱 / 崩塌

下一步：
```

## agent 自救模式

### 卡住信号

- 我给出的方案太顺，没有处理反例。
- 我只列支持理由，没有列最不利证据。
- 用户质疑“是不是漏了什么”，而我还在强化原结论。
- 我正在为自己的前一步选择辩护，而不是审查它。

### 自救动作

1. 暂停补强原方案。
2. 写出最不利证据段。
3. 把被省略证据放回判断。
4. 明确结论是否需要降级或限定。
5. 如果发现自己确实扫掉证据，直接修正，不把它包装成原本就考虑过。

### 轻量输出

```text
工具：/奥卡姆扫把
当前卡点：我的解释可能太整洁，漏掉了坏证据。
本工具给出的改写或检查：写出最不利证据段，并观察结论是否降级。
下一步：补回证据后重写结论。
```

## 误用边界

- 不要只用它指责别人。最有价值的用法是检查自己正在扫掉什么。
- 不要把任何反对意见都当成决定性反证。要看它是否真的击中核心结论。
- 不要为了显得全面而堆无关风险。只补回会改变结论强度的证据。
- 这不是悲观主义工具；它服务于更结实的结论。

## 测试运行结果

当前结论：

只要把 skill 拆成独立 issue，就自然能避免批量处理。

它最怕的事实：

1. Agent 可能虽然有独立 issue，但仍然用同一种模板快速填满多张卡。
2. Issue 标题独立，不代表实际验收独立。
3. 如果没有逐卡小测试，批量生成仍可能看起来“字段齐全”。

最不利证据段：

即使每张工具卡都有独立 issue，执行者仍可能把它们视为 77 个同构填空任务。只要它用同一套语言和同一套测试句式快速扫过去，issue 拆分就只是在形式上防批量，不能保证每个工具都被重新理解。

补回证据后的结论变化：

需要限定。更稳的结论是：按 issue 拆分只是第一层防线；还必须要求每张卡单独读源材料、单独机制转译、单独小测试、单独验收。

下一步：

在实现日志和验收命令中持续记录真实工具卡数量、当前 issue 编号和单卡测试结果，防止“独立 issue”变成形式。

测试结论：通过。本工具主动补回了会削弱原结论的不利事实，并把过强结论降级成更可靠的限定版。

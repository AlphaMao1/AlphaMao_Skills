# 007 外行做媒

## 身份

- 原书标题（中文）：外行做媒：既不“过少解释”，又不“惹恼行家”
- 英文原名：Using Lay Audiences as Decoys

- 原书分组：第一部分 通用思考工具
- 中文短命令：/外行做媒
- 别名：07、工具07、外行做媒、外行做媒：让专家对聪明外行解释，同行旁听纠偏
- 工具家族：视角切换
- 默认输出重量：中等。输出普通语言解释、外行问题、同行纠偏和修订版说明。
- 对应 issue：ISSUE-016 / TOOL-007

## 名称与思想实验

这张工具的英文原名直译更像“把外行听众当诱饵”。丹尼特说，专家之间谈话时常常会“过少解释”：他们担心把基础前提讲出来会冒犯其他专家，于是默认对方已经懂，结果双方反而各说各话。直接要求专家“多解释一点”也不管用，因为这会让他们更担心冒犯同行。

解决办法是设置一个间接场景：让专家对一群聪明、准备过材料、但仍是初学者的外行解释问题，同时让其他专家旁听。讲话者名义上是在对外行说话，所以可以放心补背景、解释术语、展开前提；旁听专家则可能突然意识到：原来对方真正想说的是这个。

所以中文短名“外行做媒”抓住了功能：外行不是事实裁判，而是沟通媒介。他们负责把“哪里听不懂、哪里跳步、哪里术语化”暴露出来；同行负责防止解释为了通俗而失真。这个工具的目标是让解释既能被聪明外行跟上，又经得住专家旁听。

## 原书机制转译

这个工具解决的是专业解释的两难：专家对专家讲得准确但外行听不懂；科普对外行讲得顺滑但可能失真。单靠专家容易省略前提，单靠外行又可能误判准确性。

“外行做媒”的机制是让聪明外行成为解释压力测试器，让同行成为准确性校准器。外行负责暴露哪里听不懂、哪里跳步、哪些术语没有解释；同行负责指出解释是否过度简化、偷换概念或丢掉关键条件。两者合起来逼出“可懂但不失真”的表达。

## 用户模式

### 触发场景

- 专家解释太术语化，目标读者听不懂。
- 科普解释太顺，但专家觉得失真。
- 你需要把复杂概念讲给跨领域读者。
- 你不确定问题出在内容难，还是解释省略了关键前提。

### 操作步骤

1. 先写一版面向聪明外行的普通语言解释。
2. 让外行提出前三个真实问题：哪里不懂、哪里跳步、哪里像黑箱。
3. 让同行只做准确性审查：失真、省略、术语偷换、边界丢失。
4. 把外行问题和同行纠偏合并。
5. 写出修订版说明，既补前提，又保留准确边界。

### 输出结构

```text
普通语言解释：

外行前三个问题：
1.
2.
3.

同行纠偏：
1.
2.
3.

修订版说明：
```

## agent 自救模式

### 卡住信号

- 我在解释中堆术语，但没有确认读者是否能跟上。
- 我为了易懂删掉了关键边界。
- 用户说“听不懂”或“这是不是过度简化了”。
- 我需要同时服务理解和准确性。

### 自救动作

1. 把当前解释改写成普通语言版本。
2. 模拟聪明外行会问的 3 个问题。
3. 再模拟同行会指出的 3 个失真风险。
4. 合并成修订版。
5. 明确哪些术语必须保留，哪些可以换成普通表达。

### 轻量输出

```text
工具：/外行做媒
当前卡点：解释要么太术语化，要么太简化。
本工具给出的改写或检查：用外行问题暴露跳步，用同行纠偏防止失真。
下一步：写出可懂但不失真的修订版说明。
```

## 误用边界

- 外行不是最终裁判。外行负责暴露沟通问题，不负责决定事实对错。
- 同行也不是唯一读者。准确但无人能懂的解释仍然失败。
- 不要把“通俗”理解成删掉所有条件；关键边界必须保留。
- 如果主题涉及高风险事实、法律、医疗或安全，修订版仍需回到权威来源核查。

## 测试运行结果

普通语言解释：

这个 skill 不会把 77 个工具都塞进主说明文件。主文件只告诉 agent 怎么找工具；每个工具的详细用法放在单独文件里。只有真正要用某个工具时，才打开那一张卡。

外行前三个问题：

1. “主说明文件”和“单独文件”分别是什么？
2. 为什么一次打开 77 个工具不好？
3. 如果只打开一张卡，怎么知道该打开哪一张？

同行纠偏：

1. 不能只说“单独文件”，应明确是 `references/tools/NNN-card.md`。
2. “避免主上下文膨胀”不是唯一目的，还包括避免 agent 一次加载太多无关内容。
3. “怎么知道打开哪张”依赖 `tool-index.json` 和路由规则，不能省略。

修订版说明：

这个 skill 的主文件只保存入口和路由规则；77 个工具的详细用法分别放在 `references/tools/NNN-card.md`。当用户点名或路由选中某个工具时，agent 先用 `tool-index.json` 找到对应卡片，再只读取这一张。这样既减少无关上下文，也避免把 77 个工具混成一团。

测试结论：通过。本工具产出了普通解释、外行问题、同行纠偏和修订版说明，展示了“可懂但不失真”的双重校准机制。

# 046 循环机制

## 身份

- 原书标题（中文）：循环：周期性重复是进化的关键
- 英文原名：Cycles
- 中文标题来源：书内译名 + 书内副题。卡片标题“寻找承担工作的重复机制”是 skill 化后的功能副题。
- 原书分组：第五部分 关于进化论的思考工具
- 中文短命令：/循环机制
- 别名：46、工具46、循环、循环：寻找承担工作的重复机制
- 工具家族：解释生成
- 默认输出重量：中等。输出循环单元、消耗、恢复、输出、反馈、积累和稳定性判断。
- 对应 issue：ISSUE-055 / TOOL-046

## 名称与思想实验

“循环”这一章把自然和工程中的重复过程放在一起看。昼夜、四季、水循环是熟悉的大循环；内燃机的奥托循环和狄塞尔循环把系统带回可继续做功的状态；克雷布斯循环把燃料转成生命活动所需能量。关键不是“重复很多次”这个表面，而是每轮都消耗、转换、恢复、输出，并为下一轮创造条件。

丹尼特还用磨箭杆的例子说明增量累积：拿木棍和石头摩擦一次几乎没效果，摩擦一百次也可能看不出变化，但几千次以后就能形成不同寻常的箭杆。很多改进之所以看起来像魔法，是因为我们的眼睛不擅长看见微小变化如何在循环中慢慢积累。

因此 `/循环机制` 要求使用者在复杂能力背后寻找真正承担工作的循环：每一轮从哪里开始，消耗什么，恢复什么，输出什么，反馈如何改变下一轮，什么东西被保留下来。没有反馈、恢复或积累的重复只是原地打转；有这些结构的循环才可能解释生命、学习、调节、计算和文化传递。

## 原书机制转译

这个工具处理“系统看似神奇地产生生命、计算、学习或调节能力”的解释缺口。很多复杂能力不是一次性动作，而是循环在承担工作：系统反复回到可继续工作的状态，同时产生输出、调节、积累、选择或修正。

`/循环机制` 的机制是寻找重复单元，并问每一轮消耗什么、恢复什么、输出什么、用什么反馈修正下一轮、有什么东西被积累下来。真正的循环不是原地重复，而是带有反馈、恢复或积累的工作机制。

它适合分析学习、训练、代谢、反馈控制、产品迭代、组织流程、研究循环、agent 调试和自我修正。

## 用户模式

### 触发场景

- 某个系统看似神奇地产生生命、计算、学习或调节能力。
- 你怀疑能力来自重复迭代，而不是单次原因。
- 一个过程不断发生，但不清楚它是否真的在积累或修正。
- 你需要区分有效循环和原地打转。

### 操作步骤

1. 写出要解释的能力或结果。
2. 找重复单元：一轮从哪里开始，到哪里结束。
3. 写每轮输入和消耗。
4. 写每轮恢复什么状态，使下一轮能继续。
5. 写每轮输出什么。
6. 写反馈信号如何影响下一轮。
7. 写积累机制：记忆、技能、能量、结构、数据、选择压力。
8. 判断循环是否长期稳定，哪些条件会让它崩溃。

### 输出结构

```text
目标能力/结果：
循环单元：

每轮输入/消耗：
每轮恢复：
每轮输出：
反馈信号：
积累机制：
稳定条件：
失效条件：
结论：
```

## agent 自救模式

### 卡住信号

- 我把学习、调试或改进写成一次性动作。
- 我看到重复，却不知道重复是否产生增量。
- 我没有写反馈信号。
- 我在同一路径反复尝试但没有积累。

### 自救动作

1. 定义一轮循环。
2. 写输入、输出、反馈和积累。
3. 检查每轮是否改变下一轮条件。
4. 如果没有反馈或积累，停止把它叫循环机制。
5. 补稳定条件和失效条件。

### 轻量输出

```text
工具：/循环机制
当前卡点：我可能把重复当成解释，或忽略真正承担工作的循环。
本工具给出的拆分：循环单元 / 消耗 / 恢复 / 输出 / 反馈 / 积累 / 稳定性。
下一步：确认每轮是否产生可保留增量。
```

## 误用边界

- 重复不等于循环机制。没有反馈或积累，只是原地打转。
- 不要把“循环”当作万能答案。要说明每轮具体做了什么工作。
- 不要忽略能量、资源和疲劳。循环长期运行需要稳定条件。
- 不要把正反馈和负反馈混淆。正反馈放大，负反馈稳定。

## 小测试问题

请用 `/循环机制` 把“学习一门语言”写成循环：输入、尝试、反馈、修正、再输入。

## 测试运行结果

目标能力/结果：

逐步学会一门语言，能听、说、读、写并在新情境中使用。

循环单元：

一次语言学习回合：接收输入 -> 尝试理解或表达 -> 获得反馈 -> 修正模型 -> 再接收更复杂输入。

每轮输入/消耗：

听到或读到语言材料、投入注意力、记忆资源、练习时间和情绪耐受。

每轮恢复：

休息、复习、间隔重复和成功交流会恢复学习动力；明确反馈会让学习者知道下一轮从哪里继续。

每轮输出：

一次理解、一次发音、一个句子、一次对话、一次写作或一次错误尝试。

反馈信号：

别人是否听懂、纠错、语法检查、阅读理解结果、发音反馈、自己是否能完成任务。

积累机制：

词汇记忆、语法模式、发音肌肉记忆、语感、常见表达脚本、错误模式清单、信心和情境经验。

稳定条件：

输入难度略高于当前水平；反馈及时；练习频率足够；错误可承受；有真实使用场景。

失效条件：

只有重复背诵但无反馈；输入太难导致放弃；错误不被发现；没有输出机会；每轮不改变下一轮策略。

结论：

语言学习不是一次性理解，而是带反馈和积累的循环。每轮尝试如果能改变记忆、策略或表达能力，就在承担学习工作；没有反馈和积累的重复只是打转。

测试结论：通过。本工具把语言学习拆成输入、尝试、反馈、修正和积累的循环，并区分了有效循环和原地重复。

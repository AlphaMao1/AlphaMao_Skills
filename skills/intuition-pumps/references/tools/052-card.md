# 052 模因

## 身份

- 原书标题（中文）：模因：不论好与坏，它都是我们人类的共生体
- 英文原名：Memes
- 中文标题来源：书内译名 + 书内副题。卡片标题“用文化选择解释非遗传设计”是 skill 化后的功能副题。
- 原书分组：第五部分 关于进化论的思考工具
- 中文短命令：/模因
- 别名：52、工具52、模因、模因：用文化选择解释非遗传设计
- 工具家族：进化机制
- 默认输出重量：中等。输出复制单位、传播渠道、变异版本、选择压力、受益对象和误用检查。
- 对应 issue：ISSUE-061 / TOOL-052

## 名称与思想实验

“模因”在原书中不是互联网流行梗的随手标签，而是严肃地把文化项看作可能的复制体。丹尼特先借道金斯的思路说明：生命进化依赖自复制体的差异性存活，基因只是地球上最熟悉的一种复制体；人类文化中也可能出现新的复制体，它们复制、变异、选择的速度甚至远快于基因。

原书给出的直观例子是布列塔尼人的独木舟。岛民不必掌握完整造船理论，只要仿制能从海上安全回来的小舟；大海淘汰不合适的形式，留下更可用的形式。于是复杂设计不一定来自基因，也不一定来自某位天才设计师，还可以来自非遗传的文化选择。语法、词语、宗教实践、技术样式，都可能经过类似的复制和筛选而变得“像被设计过”。

副题“不论好与坏，它都是我们人类的共生体”指向另一个关键：模因的适应性不等于宿主的适应性。感冒广泛存在，不说明它对人类有益；某些文化复制体也可能只对自身传播有利。短命令 `/模因` 因此要求把受益对象拆开：这个东西是对传播者有利、对社会有利，还是只是对它自己的继续复制有利。

## 原书机制转译

这个工具处理“文化现象为什么像有设计一样传播和变形”的问题。观念、口号、习俗、仪式、技术、宗教片段、流行梗，不一定是由基因直接塑造，也不一定来自某个天才的完整设计。它们可能在文化传播中经历复制、变异和选择。

`/模因` 的机制是把文化对象当作可能的复制单位来分析：它怎样被记住，怎样被复制，怎样被改写，哪些版本更容易继续传播。复杂文化设计可能来自许多轮非遗传选择，而不是一次性发明。

这张卡的关键边界是：模因不是“所有文化现象”的别名。你必须说清复制单位是什么、复制渠道是什么、变异在哪里、选择压力是什么。还要区分三种受益对象：对传播者有益，对模因自身传播有益，对社会整体有益。三者经常不同。

## 用户模式

### 触发场景

- 你要解释观念、口号、习俗、技术、宗教、流行梗为何传播。
- 一个文化现象看起来像被精心设计，但没有单一设计者。
- 你想判断某个说法为什么容易记、容易改、容易模仿。
- 你需要区分“对人有用”和“对它自己传播有用”。

### 操作步骤

1. 写出候选文化现象。
2. 明确复制单位：被复制的是一句话、一个动作、一种格式、一个故事模板、一个仪式步骤，还是一组规则。
3. 写出复制渠道：口头传播、文字、短视频、社群模仿、教育制度、平台推荐、产品使用。
4. 记录变异版本：哪些词、动作、格式、场景会被替换，哪些核心结构保持。
5. 判断选择压力：什么让某个版本更容易被记住、复述、改编、传播、制度化。
6. 区分受益对象：它对宿主有益吗，对模因复制有益吗，对社会有益吗。
7. 判断是否形成非遗传设计：是否经过多轮复制和筛选后变得更适合传播。
8. 做误用检查：复制单位不清、没有变异、没有选择压力时，不要硬说是模因解释。

## agent 自救模式

### 卡住信号

- 我把“流行”直接当成解释，没有说明为什么流行。
- 我说“这是一个模因”，但没有指出复制单位。
- 我只讲人的意图，没有看哪些版本被选择留下。
- 我把对传播有利误当成对人或社会有利。
- 当前文化设计看起来复杂，我在寻找单一发明者。

### 自救动作

1. 先圈出最小复制单位。
2. 找到至少两个变异版本。
3. 说明哪个版本更容易被记住、复制或改编。
4. 分开判断对宿主、对模因、对社会的效果。
5. 如果找不到复制和选择，放弃模因解释。

### 轻量输出

```text
工具：/模因
当前卡点：我可能只是在给文化流行贴标签，没有解释复制和选择。
本工具给出的拆分：复制单位 / 渠道 / 变异版本 / 选择压力 / 受益对象。
下一步：先说清什么被复制，再判断哪些版本更适合传播。
```

## 误用边界

- 不要把一切文化现象硬塞成单个模因。复制单位必须说清楚。
- 流行不等于有益。对模因传播有利，可能对个人或社会有害。
- 不要把模因解释写成阴谋论。很多选择可以是无意的、分散的、局部的。
- 不要忽略物质和制度条件。平台机制、教育制度、成本结构会改变选择压力。
- 如果没有可观察的复制、变异和选择，只能说是文化现象，不能强行说是模因选择。

## 小测试问题

请用 `/模因` 分析一个流行梗：它为何容易记、容易改、容易传播？并说明它对宿主、对模因自身、对社会分别有什么效果。

## 测试运行结果

候选文化现象：

流行梗“上班哪有不疯的”这一类表达。

复制单位：

不是某个固定句子本身，而是一个可替换模板：`做 X 哪有不 Y 的`，其中 X 是日常压力场景，Y 是夸张情绪反应。

复制渠道：

社交平台文案、短视频标题、评论区接龙、职场聊天、表情包改写。

| 变异版本 | 保持不变的核心 | 更易传播的原因 | 被淘汰的原因 |
| --- | --- | --- | --- |
| 上班哪有不疯的 | 压力场景 + 夸张反应 | 职场共鸣强，短，容易接话 | 使用过多后新鲜感下降 |
| 做乙方哪有不崩溃的 | 角色替换，情绪结构保持 | 能贴合特定群体，增强身份认同 | 场景窄，传播范围变小 |
| 写论文哪有不发疯的 | 场景替换，节奏保持 | 学生群体容易模仿 | 离开学业语境后弱化 |
| 人生哪有不抽象的 | 扩大到泛生活场景 | 适用范围更广，便于二次改写 | 太泛可能失去具体共鸣 |

选择压力：

- 容易记：句式短，节奏稳定，情绪强。
- 容易改：只需要替换场景和情绪词。
- 容易传播：能让发布者表达压力，同时获得同类人的回应。
- 容易存活：平台评论区适合接龙式变异。

对宿主的收益/成本：

收益是快速表达情绪、获得共鸣、降低解释成本。成本是可能把复杂问题压成玩笑，削弱真正解决问题的动力。

对模因自身传播的收益：

越短、越夸张、越容易替换场景，越适合继续复制。对模因来说，真实解决压力不是必要条件，能被继续引用才是传播优势。

对社会的收益/成本：

收益是让一些被压抑的共同体验被看见。成本是情绪模板可能泛化，导致讨论停在宣泄和自嘲。

结论：

这个梗适合用模因分析，因为它有清楚复制单位、多个变异版本、明显传播渠道和选择压力。它的“设计感”不是来自某个总设计师，而是来自许多用户在传播中不断保留更短、更好改、更能引发共鸣的版本。

测试结论：通过。本工具用复制、变异和选择解释了一个非遗传文化设计，并区分了对宿主、对模因自身和对社会的不同效果。

# 012 深马

## 身份

- 原书标题（中文）：什么是“深马”：爱就一个字
- 英文原名：What Is a Deepity?
- 中文标题来源：书内译名 + 书内副题。卡片标题“拆开‘真但无聊’和‘深但可疑’”是 skill 化后的功能副题。
- 原书分组：第一部分 通用思考工具
- 中文短命令：/深马
- 别名：12、工具12、深马、深马：拆开“真但无聊”和“深但可疑”
- 工具家族：概念澄清
- 默认输出重量：轻到中等。输出平凡真版本、深刻可疑版本、信息量和可验证性判断。
- 对应 issue：ISSUE-021 / TOOL-012

## 名称与思想实验

“深马”来自一个典型例子：一句话可以同时像“深刻”和“废话”。它的字面版本往往是真的，但太平凡；它让人觉得深刻的版本又往往证据不足。这个名字提醒你警惕一种滑动：作者先说一个大家会点头的弱版本，再借它的正确性偷渡一个更强、更玄的版本。

所以 `/深马` 不是在嘲笑难句，也不是反对隐喻。它是在问：这句话的“深刻感”到底来自真实洞见，还是来自两个版本之间的含糊切换？

## 原书机制转译

深马处理的是一种靠歧义制造深刻感的句子。它通常有两个读法：一个读法是真的，但信息量很低；另一个读法听起来深刻，但缺少证据或可检验含义。句子的震撼感来自两个版本之间的滑动。

`/深马` 的机制是把一句看似深刻的话拆成两个明确版本：平凡真版本和深刻可疑版本。然后分别检查真假、信息增量和可验证性。如果真版本没有增量，深版本又站不住，就把它标记为深马。

## 用户模式

### 触发场景

- 一句话听起来很深、很震撼，但你说不清它增加了什么信息。
- 一段文字让人点头，却无法指导判断或行动。
- 作者在字面和隐喻之间滑动。
- 你需要判断一句金句、鸡汤、哲学判断或战略口号是否真有内容。

### 操作步骤

1. 摘出原句。
2. 写出“平凡真版本”：它在最保守解释下是什么意思。
3. 写出“深刻可疑版本”：它让人觉得深刻的强解释是什么。
4. 分别判断真假、信息量和可验证性。
5. 如果平凡真版本没增量、深刻可疑版本缺证据，就标为深马。
6. 要求作者选择一个明确版本，或补充机制和证据。

### 输出结构

```text
原句：
平凡真版本：
深刻可疑版本：
真值判断：
信息增量：
可验证性：
判断：有洞见 / 深马 / 需要澄清
```

## agent 自救模式

### 卡住信号

- 我写出了一句漂亮但无法操作的话。
- 我用抽象口号替代机制说明。
- 用户问“这句话到底什么意思”，而我只能继续解释得更抽象。
- 当前判断看似深刻，但不能改变任何下一步。

### 自救动作

1. 抽出可疑句子。
2. 写平凡真版本和深刻可疑版本。
3. 检查哪个版本有证据和增量。
4. 如果没有增量，删掉或改写。
5. 如果有洞见，补出机制、边界或可验证含义。

### 轻量输出

```text

下一步：保留有证据和增量的版本，删掉或澄清其余部分。
```

## 误用边界

- 不要把诗性语言一律当垃圾。文学、比喻和启发性表达可以有价值。
- 问题不在含蓄，而在用含糊冒充洞见。
- 不要用“这是深马”逃避理解难句。先拆版本，再判断。
- 有些句子需要背景知识才能显示信息量，不能只凭第一感觉判定。

## 小测试问题

请用 `/深马` 检查这句话：“AI 不是工具，而是人类认知的镜子。”

## 测试运行结果

原句：

AI 不是工具，而是人类认知的镜子。

平凡真版本：

AI 的输出会反映训练数据、人类提示和使用者的思维方式，所以它有时能暴露人的表达习惯和判断偏好。

深刻可疑版本：

AI 的本质不是工具，而是某种能够揭示人类认知本质的特殊存在。

真值判断：

平凡真版本大体成立，但信息量有限。深刻可疑版本需要解释“本质不是工具”“认知的镜子”到底是什么意思，以及它如何被验证。

信息增量：

平凡真版本提醒我们可以观察提示词和输出中的认知偏好，但不算很新。深刻可疑版本如果不补机制，主要提供气氛。

可验证性：

平凡真版本可以通过比较提示词、输出和用户反馈来验证。深刻可疑版本暂时不可验证。

判断：

需要澄清，偏深马。可保留的版本是：AI 工具在交互中会反映用户的表达、假设和偏好，因此可以作为观察认知习惯的材料；但它仍然是工具，不需要把它神秘化。

测试结论：通过。本工具把一句深刻感口号拆成平凡真版本和深刻可疑版本，并保留了有操作含义的部分。

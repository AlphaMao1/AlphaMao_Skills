# 021 近似算子

## 身份

- 原书标题（中文）：近似算子：达尔文渐进主义的启示
- 英文原名：The Sorta Operator
- 中文标题来源：书内译名 + 书内副题。卡片标题“把二分问题改成渐进问题”是 skill 化后的功能副题。
- 原书分组：第二部分 关于意义和内容的思考工具
- 中文短命令：/近似算子
- 别名：21、工具21、近似算子、近似算子：把二分问题改成渐进问题
- 工具家族：概念澄清
- 默认输出重量：中等。输出子能力、梯度等级、功能阈值、边界模糊处和二分改写。
- 对应 issue：ISSUE-030 / TOOL-021

## 名称与思想实验

“近似算子”可以理解成一个把硬开关变成程度判断的操作符。很多问题看起来在问“有没有”：有没有理解、有没有意识、算不算物种、会不会读书。但真实能力常常不是突然从 0 跳到 1，而是由很多接近、局部、渐进的能力累积出来。

所以这个名字里的“近似”不是含糊敷衍，而是把问题改成：在哪些子能力上已经接近，在哪些任务阈值下足够算，哪些边界还不够。它把“算不算”改成“算到什么程度、在什么任务里算”。

## 原书机制转译

这个工具处理“到底有没有”的硬二分：有没有意识、有没有信念、是不是物种、算不算理解、会不会读书。很多复杂能力不是一次性出现，而是由多个近似能力逐渐累积：差不多能识别、差不多能复述、差不多能迁移、差不多能纠错。高层描述常常在这些能力达到某个功能阈值后变得有用。

`/近似算子` 的机制是把二分判断改成梯度问题。它要求你拆出目标能力的子能力，为每个子能力标注从无到强的连续等级，再说明哪些组合已经足够支持高层说法。这样可以避免强行寻找“第一个真正有意识者”“第一只真正的物种”“第一刻真正理解”的假边界。

近似不是逃避标准。好的近似必须有功能标准：在什么任务中足够好、在哪些边界处仍不足、什么证据会让等级上升或下降。

## 用户模式

### 触发场景

- 问题被迫变成“有没有意识、有没有信念、是不是物种、算不算理解”等硬二分。
- 你怀疑能力是逐步形成的，而不是突然开关。
- 你需要比较孩子、模型、动物、组织或系统的能力程度。
- 你正在寻找“第一例”，但边界明显连续或模糊。

### 操作步骤

1. 写出原始二分问题。
2. 把目标能力拆成 4-8 个子能力。
3. 给每个子能力设置梯度等级，例如 0-4 或 弱/中/强。
4. 为每个等级写功能标准，而不是只写形容词。
5. 判断当前对象在每个子能力上的等级。
6. 说明哪些组合足够支持高层描述，哪些还不够。
7. 把原问题改写为“在什么任务和阈值下，算到什么程度”。

### 输出结构

```text
原始二分问题：
目标能力：

| 子能力 | 梯度标准 | 当前等级 | 证据 |
| --- | --- | --- | --- |

足够支持高层描述的组合：
边界模糊处：
改写后的问题：
结论：
```

## agent 自救模式

### 卡住信号

- 我在回答“算不算 X”，但边界本身连续。
- 我想找第一个例子，却发现前后差异都是微小变化。
- 我用“有/没有”压扁了明显不同程度的能力。
- 我说“差不多”，但没有功能标准。

### 自救动作

1. 把二分词圈出来：有/没有、算/不算、会/不会、真/假。
2. 拆出目标能力的子能力。
3. 给每个子能力写可观察梯度。
4. 标出当前对象的等级和证据。
5. 把结论改成任务相关阈值判断。

### 轻量输出

```text
工具：/近似算子
当前卡点：问题被压成硬二分，但能力可能是渐进的。
本工具给出的拆分：目标能力 / 子能力梯度 / 功能阈值 / 边界模糊处。
下一步：用“在某任务中达到某等级”替代简单算或不算。
```

## 误用边界

- 近似要有功能标准，不能用“差不多”掩盖具体差异。
- 不要把所有二分都消解成连续谱。法律、合规、接口验收等可能需要外部阈值。
- 不要用梯度逃避决策。需要行动时，要明确采用哪个阈值。
- 不要只列等级，不写证据和任务。等级必须能被观察或测试。

## 小测试问题

请用 `/近似算子` 给“会读书”列梯度：识字、复述、解释、迁移、批判、创造性使用。

## 测试运行结果

原始二分问题：

这个人会不会读书？

目标能力：

会读书。

| 子能力 | 梯度标准 | 当前等级 | 证据 |
| --- | --- | --- | --- |
| 识字 | 0 不识字；1 识别少量词；2 能读普通句子；3 能读长段落；4 能处理专业文本 | 待测 | 读 aloud、词义理解测试 |
| 复述 | 0 不能复述；1 复述零散词；2 复述主要情节；3 复述论证结构；4 可压缩成清晰摘要 | 待测 | 让其用自己的话复述 |
| 解释 | 0 只重复原文；1 解释个别句子；2 解释段落含义；3 解释作者主张和理由；4 解释隐含前提和语境 | 待测 | 追问“这句话为什么成立” |
| 迁移 | 0 不能迁移；1 套用表面例子；2 用到相似情境；3 用到新问题；4 能调整概念后迁移 | 待测 | 给新案例，看能否应用 |
| 批判 | 0 全盘接受；1 找明显错误；2 找证据缺口；3 找论证结构问题；4 能提出强反例和替代理论 | 待测 | 要求指出文本最弱处 |
| 创造性使用 | 0 无输出；1 拼接原文；2 改写表达；3 生成新框架；4 用文本创造新问题或方案 | 待测 | 要求基于文本设计方案 |

足够支持高层描述的组合：

日常意义的“会读书”可能只要求识字 2、复述 2、解释 1。研究或工作中的“会读书”至少需要解释 3、迁移 2、批判 2。深度阅读则需要解释、迁移、批判、创造性使用都达到较高水平。

边界模糊处：

一个人能读完小说并复述情节，但不能解释论证或迁移概念。说他“会读书”在休闲阅读任务中成立，在学术研究任务中不充分。

改写后的问题：

不要问“会不会读书”，而问“在当前任务中，TA 的识字、复述、解释、迁移、批判和创造性使用分别达到什么等级，是否达到任务阈值”。

结论：

“会读书”不是单一开关，而是一组渐进能力。根据任务阈值不同，同一个人可以在某些意义上会读，在另一些意义上还不会。

测试结论：通过。本工具把硬二分问题改成了有功能标准的能力梯度，并明确了不同任务的阈值。

# 075 自我人类学

- 对应 issue：ISSUE-084 / TOOL-075

## 名称与思想实验

“简单的自我人类学”借帕特里克·哈耶斯的“朴素物理学”说明：如果要给机器人写入人类日常常识，很多真实现象会被常识排除在外。虹吸和移液器在朴素流体物理学中显得“不可能”，毛巾吸水和水泵抽水却显得自然。哈耶斯并不以为这套理论为真；它只是人们实际用来生活和互动的常识地图。

丹尼特把这种做法转到哲学：如果哲学家把自己和同侪共享的直觉当作公理，努力消除矛盾、整理成理论，却又误以为自己发现的是世界本身，那就成了天真的自我人类学。更好的版本是“复杂的朴素人类学”：像研究异域文化一样暂时悬置信与不信，记录常识映像如何运作，再拿它和科学映像协调。

短命令 `/自我人类学` 因此要求把“我觉得显然”降级为材料。哲学家、语言学家和其他专家的直觉会被理论偏好污染；有时必须询问非专业者或实际使用者，看看直觉是否真是共享常识。反直觉发现不是自动敌人，可能正是常识地图需要修正的地方。

## 原书机制转译

这个工具处理“这很直观”“我们都会这样想”这类哲学论证。丹尼特提醒，哲学家的直觉可能只是某个受教育群体、语言群体、专业训练群体的常识人类学，而且还可能被理论训练污染。坐在椅子上觉得“大家都会这么想”，不是全人类共识。

`/自我人类学` 的机制是把自己的直觉降级为研究材料：先记录我自己的反应，再找非专业者测试，收集分歧，分析直觉可能来自语言习惯、文化背景、专业训练、情绪反应还是任务表述。最后再判断哪些直觉应保留、修正或丢弃。

这个工具不是要抛弃直觉，而是让直觉进入证据链：从“真理来源”变成“需要解释的心理和文化事实”。

## 用户模式

### 触发场景

- 你想用“这很直观”“我们都会这样想”支持哲学判断。
- 你怀疑自己的专业训练正在污染判断。
- 一个概念争论依赖常识直觉，但不知道常识是否真的一致。
- 你需要把直觉与科学映像、实际案例或他人理解协调。

### 操作步骤

1. 写出待检验命题：自由、原因、知识、身份、责任、意识等。
2. 记录自己的第一反应：直觉结论、强度、理由、情绪、身体反应。
3. 写出问题表述，避免暗示答案。
4. 找 3 到 5 个非专业者提问，记录原话，不急着纠正。
5. 收集分歧：谁同意，谁反对，谁卡在词义，谁改变问题。
6. 分析直觉来源：语言习惯、文化背景、教育、专业训练、情绪、案例细节。
7. 与科学映像或实际机制协调：哪些直觉有保留价值，哪些需要修正。
8. 输出保留、修正或丢弃决定；不要把个人直觉冒充全人类共识。

## agent 自救模式

### 卡住信号

- 我说“显然”“大家都会觉得”，但没有证据。
- 我把专业哲学直觉当成普通常识。
- 我没有记录自己的直觉来源。
- 我没有问非专业者或检查分歧。
- 当前问题需要协调常识映像和科学映像。

### 自救动作

1. 把我的直觉写成材料，而不是结论。
2. 标出直觉强度和可能来源。
3. 设计非诱导性问题。
4. 收集或请求用户提供他人反应。
5. 把直觉分为保留、修正、丢弃。

### 轻量输出

```text
工具：/自我人类学
当前卡点：我可能把自己的直觉当成了全人类共识。
本工具给出的拆分：我的直觉 / 非专业者反应 / 分歧来源 / 科学映像协调 / 保留修正丢弃。
下一步：把直觉当材料记录，而不是直接当真理使用。
```

## 误用边界

- 不要把坐在椅子上的自我感觉冒充全人类共识。
- 不要伪造访谈。如果没有真实受访者，只能输出访谈计划或示范表，不能当作数据。
- 非专业者多数意见也不是自动真理；它只是常识人类学材料。
- 不要用这个工具贬低专业训练。专业直觉有价值，但要说明来源和适用范围。
- 不要把“直觉有文化差异”误解成“没有任何问题可以判断”。

## 小测试问题

请用 `/自我人类学` 对“自由、原因、知识、身份”各问 3 个非专业者，记录他们和你的差异。

## 测试运行结果

说明：

下面是示范性记录模板，展示如何使用本工具；它不冒充真实访谈数据。真实使用时应替换为实际受访者原话。

待检验命题：

自由、原因、知识、身份这四个概念的常识直觉是否与我的哲学直觉一致。

我的直觉：

- 自由：不需要绝对随机，更需要理由响应和控制能力。
- 原因：原因不一定是单点事件，可能是机制和条件网络。
- 知识：知识不只是确信，还需要可靠来源和可纠错。
- 身份：个人身份不是单一事实，可能由身体、心理、社会和叙事共同支撑。

可能污染来源：

读过哲学和认知科学，倾向于拆概念和反单一本质。

| 概念 | 受访者 | 原话摘要 | 与我的差异 | 可能来源 |
| --- | --- | --- | --- | --- |
| 自由 | A | “自由就是没人逼我，我想做就做。” | 更重视外部强迫 | 日常行动语境 |
| 自由 | B | “如果都被决定了，那就不算自由。” | 把自由和非决定混在一起 | 常见自由意志直觉 |
| 自由 | C | “能为后果负责才算自由。” | 接近实践责任标准 | 法律/道德语境 |
| 原因 | A | “最直接导致它发生的那个就是原因。” | 偏单点原因 | 日常追责需求 |
| 原因 | B | “很多条件一起造成。” | 接近机制/条件网络 | 经验性思考 |
| 原因 | C | “要看你问这个问题是为了修什么。” | 把原因和干预目标联系 | 实用主义倾向 |
| 知识 | A | “亲眼见到才算知道。” | 更重感知直接性 | 日常信任规则 |
| 知识 | B | “网上查到也算，但要看来源。” | 接近可靠来源标准 | 信息环境经验 |
| 知识 | C | “我可能知道但说不清原因。” | 更宽容隐性知识 | 技能经验 |
| 身份 | A | “身体还是那个身体就是同一个人。” | 偏身体连续 | 日常识别习惯 |
| 身份 | B | “记忆和性格变了就像另一个人。” | 偏心理连续 | 关系经验 |
| 身份 | C | “别人还把你当那个人也重要。” | 加入社会承认 | 社会关系语境 |

分歧模式：

非专业者反应不是一套统一常识，而是随语境变化：追责时偏单点原因，行动时偏外部强迫，关系时偏心理身份，信息环境中偏来源可靠。

应保留的直觉：

我的概念拆分有助于解释分歧，但不能替代常识材料。

应修正的直觉：

不能说“大家都知道自由不需要随机”。至少要承认很多非专业者会把自由和非决定联系起来。

应丢弃的直觉：

丢弃“我的哲学直觉就是普通常识”的假设。

下一步证据：

做真实小样本访谈，保留原话；改写问题表述，避免诱导；必要时按语境分别问自由、责任、原因和身份。

测试结论：通过。本工具把自己的直觉当作研究材料，设计了非专业者比较表，并明确示范不冒充真实访谈数据。

# 059 功能链条

## 身份

- 原书标题（中文）：听声辨牌：感受质的意义之四
- 英文原名：The Tuned Deck
- 中文标题来源：书内译名 + 书内副题。卡片标题“先穷尽功能链条，再谈困难问题”是 skill 化后的功能副题。
- 原书分组：第六部分 关于意识的思考工具
- 中文短命令：/功能链条
- 别名：59、工具59、听声辨牌、听声辨牌：先穷尽功能链条，再谈困难问题
- 工具家族：意识拆解
- 默认输出重量：中等。输出表现能力、信息路径、功能机制、连接关系、剩余直觉和困难问题复评。
- 对应 issue：ISSUE-068 / TOOL-059

## 名称与思想实验

“听声辨牌”来自纸牌魔术师拉尔夫·赫尔的招数。他宣称自己能通过纸牌发出的声音辨认观众选中的牌，还把它命名为 The Tuned Deck。秘密不在听力，而在名字中的定冠词：观众以为眼前有一个单一的新招数，于是不断寻找“这个”大秘密；实际上赫尔轮换使用一组普通纸牌手法，在观众验证某个猜想前切到另一个手法，让专家们一次次觉得自己刚要抓住谜底又落空。

丹尼特用这个魔术类比查尔莫斯的“困难问题”。意识里确实有很多难题：如何报告所见所闻、如何在例行活动出错时启动注意、如何追踪多个运动物体、话到嘴边为什么说不出、为什么笑话会好笑。这些问题很难，但仍是可以拆成信息处理、注意、记忆、报告、行动等机制的功能问题。所谓“困难问题”也许像 The Tuned Deck 一样，把一包不同问题包装成一个看似单一、不可破解的大谜团。

短命令 `/功能链条` 因此要求先防止“算术错误”：不要把已经解释过的现象又数一遍，也不要把多个普通难题合并成神秘残余。它不是提前宣布没有残余问题，而是要求先列出所有功能链条，检查哪些能力已被解释、哪些被重数、哪些仍缺机制，然后再判断剩下的到底是什么。

## 原书机制转译

这个工具处理“功能解释总像是漏掉了什么”的感觉。魔术效果给人的启发是：观众看到一个不可思议能力，常常是因为隐藏的信息链条没有被看见。能力看起来像魔法，不代表它需要神秘中介；也可能只是获取、辨别、注意、记忆、报告和反应等环节被巧妙连接了。

`/功能链条` 的机制是：在谈“困难问题”前，先把主体表现出的能力逐项列出来，再为每项能力寻找可能机制，检查机制之间如何连接。很多被误认为“本质缺口”的东西，可能其实是未拆开的功能链条。

这个工具不要求你否认剩余问题。它只是要求先穷尽可拆的功能解释：哪些信息被获取，怎样被辨别，如何进入注意和记忆，怎样产生报告和行动。拆完以后，如果还有剩余直觉，再更精确地说明剩余在哪里。

## 用户模式

### 触发场景

- 你遇到“意识困难问题”，觉得功能解释总漏掉什么。
- 一个系统表现出像魔术一样的能力，你不知道信息从哪里来。
- 讨论停在“这只是功能解释，真正体验还没解释”。
- 你需要先穷尽可解释链条，再判断是否还有真正残余问题。

### 操作步骤

1. 写出表面现象：主体做到了什么，观众/观察者觉得神秘在哪里。
2. 把能力拆成可检查环节：信息获取、特征辨别、注意选择、记忆保持、推理连接、报告输出、行动反应。
3. 为每个环节列出可能机制，不要求一次确定，只要提出可测试路径。
4. 检查链条连接：上一步的输出怎样成为下一步的输入。
5. 找出被误认为神秘中介的环节：例如“知道”“看见”“感觉到”“直接把握”。
6. 评估功能解释是否覆盖了表面能力。
7. 最后再问是否还有剩余问题，并把剩余问题写成更窄的形式。

## agent 自救模式

### 卡住信号

- 我直接说“功能解释遗漏本质”，但没列出功能链条。
- 我把“知道”“体验”“识别”当成不可拆的能力。
- 我没有追踪信息从哪里进入系统。
- 我没有说明注意、记忆、报告和行动之间如何连接。
- 当前神秘感可能来自隐藏路径，而不是新实体。

### 自救动作

1. 把表面能力列成若干功能环节。
2. 对每个环节提出至少一个可能信息路径。
3. 检查环节之间的输入输出。
4. 标出仍然没有解释的具体能力。
5. 只对剩余部分谈困难问题。

### 轻量输出

```text
工具：/功能链条
当前卡点：我可能还没穷尽功能解释，就宣布有困难问题。
本工具给出的拆分：获取 / 辨别 / 注意 / 记忆 / 连接 / 报告 / 反应。
下一步：先画出信息链条，再判断还剩什么。
```

## 误用边界

- 不要因为功能解释不满足旧直觉，就断言它遗漏了本质。
- 不要把“可提出功能链条”误当成“已经证明链条真实”。还要看证据。
- 不要用功能分解消除所有开放问题。拆完以后可能仍有剩余，但要更具体。
- 不要把魔术类比用成阴谋式解释。它只是提醒你寻找隐藏信息路径。
- 如果某环节确实没有机制假设，要诚实标为缺口。

## 小测试问题

请用 `/功能链条` 拿一个魔术效果，写出观众看到的现象和可能的信息路径。然后判断是否还有困难问题。

## 测试运行结果

表面现象：

魔术师背对观众，观众从牌堆里抽一张牌并放回。魔术师只听洗牌和翻牌的声音，就说出了是哪一张牌。

神秘感来源：

观众以为魔术师没有视觉信息，却获得了牌面信息。能力看起来像“听声直接知道牌”。

| 功能环节 | 需要解释的能力 | 可能机制/信息路径 | 可检查证据 |
| --- | --- | --- | --- |
| 获取 | 魔术师如何获得关于选牌的信息 | 牌被预先强迫选择；牌背或边缘有细微标记；助手给声音暗号；牌堆顺序被记住 | 换新牌、取消助手、打乱流程、观察是否仍成功 |
| 辨别 | 如何区分具体牌 | 不同动作对应不同位置；观众放回位置发出不同声音；魔术师实际在追踪牌序 | 改变桌面材质、改变洗牌方式、让观众远离桌面 |
| 注意 | 如何从杂音中锁定关键信号 | 魔术师训练过特定声音线索，或只需确认少量候选 | 增加干扰音、改变动作节奏 |
| 记忆 | 如何记住牌堆结构或候选范围 | 预排牌序、记忆牌组、只在有限选择中操作 | 观众完全自由洗牌后效果是否消失 |
| 报告/行动 | 如何给出确定答案 | 根据强迫选择、暗号或牌序推断后报出牌名 | 记录多轮失败率和流程变化 |

链条连接：

一种可能链条是：魔术师先通过强迫选择限制候选牌，再通过放回位置或助手暗号获取信息，利用记忆中的牌序缩小范围，最后报告牌名。观众看到的是“听声辨牌”，实际可能是多个信息路径连接后的结果。

被误认为神秘中介的环节：

“听声直接知道牌”这个说法把获取、辨别、记忆和推断压成一个神秘能力。

功能解释覆盖情况：

这些功能链条不证明具体魔术一定这样做，但足以说明表面现象不必立刻诉诸神秘能力。要继续判断，需要逐项封闭可能信息路径。

剩余问题：

若在完全新牌、无助手、无预排、无视觉、无触觉、无流程控制的条件下仍稳定成功，剩余问题才会变得更强。此时问题也应写成具体缺口：信息如何进入系统，而不是直接说“魔法存在”。

测试结论：通过。本工具先穷尽了获取、辨别、注意、记忆、报告等功能链条，再把剩余问题缩小到具体信息路径缺口。

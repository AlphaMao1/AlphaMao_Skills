# 036 基因子程序

## 身份

- 原书标题（中文）：什么是基因：基因就像软件中的子程序
- 英文原名：What Is a Gene?
- 中文标题来源：书内译名 + 书内副题。卡片标题“把基因当作可调用子程序”是 skill 化后的功能副题。
- 原书分组：第五部分 关于进化论的思考工具
- 中文短命令：/基因子程序
- 别名：36、工具36、什么是基因、什么是基因：把基因当作可调用子程序
- 工具家族：进化机制
- 默认输出重量：中等。输出基因功能、调用上下文、调控条件、协同因素、环境影响和降级表述。
- 对应 issue：ISSUE-045 / TOOL-036

## 名称与思想实验

“什么是基因”这一章反对把基因组想成一套从头到尾建造某个生物的主程序。丹尼特借用道金斯和雷德利的比喻：大多数基因更像词典里的词，或者更准确地说，像计算机系统里的工具箱子程序。不同程序可以反复调用同一个子程序；同样，不同发育过程也会在不同时间、地点和上下文中调用相同或相近的基因。

原书用文学和软件作对照：《大卫·科波菲尔》和《麦田里的守望者》用的英语词汇大量重叠，差异不在“词典完全不同”，而在词被调用、排列和组合的方式。人和老鼠的胚胎也借用了哺乳动物发育的共同工具箱，差异来自哪些基因在什么位置、什么时机、以什么调控级联被启动，而不是每个物种都有一套完全独立的从零开始说明书。

因此 `/基因子程序` 要求使用者把“某基因决定某性状”降级成“某基因在特定上下文中被调用，参与某个中间过程”。真正要问的是：它编码或调控什么，在哪些细胞和发育阶段表达，被什么信号打开或关闭，和哪些其他子程序协同，最终怎样影响性状。

## 原书机制转译

这个工具处理“某基因决定某性状”的过度简化。基因不像一个单独施工队，自己从头到尾建出性状；它更像工具箱里的可调用子程序，会在特定细胞、时机和环境中被调控网络调用，并和其他基因、发育过程、身体状态和外部环境共同产生结果。

`/基因子程序` 的机制是把“决定”改写为“参与某过程”。你要问：这个基因编码或调控什么，它在哪些细胞中表达，什么时候被调用，由什么信号打开或关闭，和哪些其他基因或环境因素协同，最终影响哪个中间过程。

这张卡适合做概念澄清，不适合直接做医学遗传咨询或个体风险判断。涉及具体疾病、检测结果或治疗决策时，需要专业来源和临床语境。

## 用户模式

### 触发场景

- 你看到“某基因决定某性状”的简单说法。
- 媒体、论文摘要或科普把复杂性状压成单基因故事。
- 你要解释基因、调控网络、环境和发育过程的关系。
- 你需要把基因因果从“命运决定”降级成“参与过程”。

### 操作步骤

1. 写出原始基因决定论说法。
2. 写出该基因编码、调控或影响的中间过程。
3. 列出调用上下文：细胞类型、发育阶段、组织位置、身体状态。
4. 列出调控条件：哪些信号、转录因子、表观状态或反馈会影响表达。
5. 列出协同因素：其他基因、通路、激素、营养、行为和环境。
6. 把性状拆成多个中间步骤，找到该基因参与哪一步。
7. 将结论改写为“参与/影响/提高概率/在某条件下贡献”，不要写“单独决定”。

### 输出结构


## agent 自救模式

### 卡住信号

- 我把一个复杂性状归给单个基因。
- 我写“决定”，但没有细胞、时机、调控和环境。
- 我跳过中间过程，直接从基因到行为或性格。
- 当前解释听起来像基因命运论。

### 自救动作

1. 把“决定”替换成待检验的参与关系。
2. 写中间过程和调用上下文。
3. 补调控、协同和环境因素。
4. 把结论降级为范围限定的影响。
5. 若涉及个人医学判断，停止泛化并要求专业语境。

### 轻量输出

```text
工具：/基因子程序
当前卡点：我可能把基因写成单独施工队。
本工具给出的拆分：编码/调控功能 / 调用上下文 / 调控条件 / 协同因素 / 环境因素。
下一步：把“决定性状”改成“在某条件下参与某过程”。
```

## 误用边界

- 不要把基因当单独施工队。基因需要上下文才有功能。
- 不要把“基因参与”说成“个体命运已定”。
- 不要用环境因素否认遗传影响。问题是关系结构，不是二选一。
- 不要把这张卡用于具体医学或遗传咨询结论。那需要最新专业资料和临床背景。

## 小测试问题

请用 `/基因子程序` 把“身高基因”改写成多因素说明：生长激素、营养、调控、环境、多个基因。

## 测试运行结果

原说法：

某人身高由“身高基因”决定。

更精确对象：

身高是一组发育结果，涉及骨骼生长、软骨细胞增殖、激素调控、营养状态、健康状况和多个遗传变异的共同影响。

基因参与的过程：

相关基因可能影响生长板发育、细胞增殖、骨骼成熟、激素通路、营养代谢或身体比例。它们参与的是中间过程，不是单独“建造身高”。

调用上下文：

这些基因在特定组织和阶段更重要，例如发育期的骨骼、生长板、内分泌相关组织；成年后同样基因状态不一定继续以同样方式影响身高增长。

调控条件：

生长激素、甲状腺激素、性激素、发育阶段、营养状态、睡眠、疾病和反馈通路都会影响相关过程是否充分发生。

协同因素：

多个基因和通路共同作用。一个基因变异可能只贡献很小效应；某些罕见变异可能效应较大，但仍要经过发育和生理系统表现出来。

环境因素：

营养、慢性疾病、童年压力、运动、睡眠和医疗条件会影响遗传潜力是否被实现。

可保留结论：

遗传因素显著参与身高差异；某些基因或变异会影响与身高相关的发育过程。

应删除/降级的说法：

删除“一个身高基因决定身高”。改写为：身高由多个遗传因素与发育、激素、营养和环境条件共同塑造；具体基因通常是在特定上下文中参与某些生长过程。

测试结论：通过。本工具把单基因决定论改写为基因子程序、调控网络、发育阶段和环境因素共同作用的说明。

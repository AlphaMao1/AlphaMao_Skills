# Router Tests

本文件属于 `ISSUE-008`。它用于测试路由是否塌缩到少数高频工具或同一工具家族。

## 运行规则

对每个测试问题输出：

- 1 个 `建议先用`
- 4 个 `可选探索`
- 5 个固定槽位都必须出现
- 每个候选必须包含原书标题/英文原名（如有）、名字在书里的背景、名称与当前动作的对应关系、家族、工具实际做什么、理由和不适用边界
- 每个候选的名字背景必须来自对应工具卡的 `身份`、`名称与思想实验` 和 `原书机制转译`，不能只根据索引字段补写
- 高频工具被推荐时必须说明为什么这次仍然值得用

## 通过标准

- 每组推荐至少覆盖 3 个工具家族，除非测试问题本身明确要求单一领域。
- `low_frequency_explorer` 不能使用高频工具，除非没有结构适配的低频工具。
- 不能连续 3 个测试都把同一个工具放在 `most_relevant`。
- 如果 8 个测试中超过 4 次推荐同一个高频工具，必须记录塌缩风险。
- 卡片未完成时，测试只检查推荐质量，不允许临时应用或补写卡片。

## 测试问题

### T01 论证批评

我想批评一个 AI 圈常见观点，但怕自己打的是稻草人。

期望覆盖：论证检验、视角切换、概念澄清。

### T02 显然性跳步

这个产品需求里很多人说“当然应该支持自动化”，但我觉得这里有跳步。

期望覆盖：论证检验、概念澄清、低频探索。

### T03 魔法解释

我解释一个系统时总觉得里面有个聪明的小人在做决策。

期望覆盖：解释生成、反直觉破局、agent 自救。

### T04 设计感

一个组织看起来像被人精心设计过，但实际上可能只是长期演化出来的。

期望覆盖：进化机制、解释生成、视角切换。

### T05 意识直觉

我在讨论意识体验时，对方一直说“你无法想象没有体验的系统”。

期望覆盖：意识拆解、反直觉破局、概念澄清。

### T06 自由意志

我们争论自由意志时总卡在“决定论等于不自由”。

期望覆盖：自由责任、概念澄清、反直觉破局。

### T07 问题是否值得

我有个哲学问题很精巧，但不确定是否值得继续研究。

期望覆盖：元认知、论证检验、低频探索。

### T08 agent 卡住

Agent 连续两轮解释都绕回同一个抽象词，没有产生新证据。

期望覆盖：agent 自救、解释生成、概念澄清。

## 名称背景验收

每组测试还要检查：

- 用户不熟悉该工具时，仅看候选说明能知道名字指向的书中画面。
- 候选说明能说清这个画面暴露的思考陷阱，以及它如何转成当前操作。
- 不能把 skill 自拟的短命令写成原书标题。

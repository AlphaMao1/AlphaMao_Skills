# Taxonomy

本文件属于 `ISSUE-004`。它只定义初始工具家族与推荐槽位，不转译任何单张工具卡。

## 工具家族

| 家族 | 用途 |
|---|---|
| 论证检验 | 检查命题、前提、反问、话术、强弱样本和隐藏证据。 |
| 概念澄清 | 拆开概念边界、二分问题、层级、表征和理解程度。 |
| 解释生成 | 把看似聪明、神奇或整体性的现象拆成可工作的机制。 |
| 视角切换 | 在常识映像、科学映像、意向立场、系统外视角之间切换。 |
| 反直觉破局 | 用思想实验或反图像打断误导性直觉。 |
| 进化机制 | 用选择、适应、信号、物种和文化复制解释设计感。 |
| 意识拆解 | 拆解僵尸、感受质、第一人称报告、身份和责任中的混淆。 |
| 自由责任 | 处理决定论、选择、公平、历史事实和道德责任。 |
| 元认知 | 判断问题是否值得做、如何读强者、如何对待自己的直觉。 |
| agent 自救 | 横向家族。仅当 agent 明确卡住时，用于选择能恢复推进的工具。 |

## 推荐槽位

每次路由推荐必须填满 5 个槽位：

1. `most_relevant`：最直接匹配当前问题的工具。
2. `different_family`：同一问题的不同家族替代路径。
3. `concept_boundary`：澄清概念、层级、边界或变量的工具。
4. `counterintuitive_breakout`：打破误导性直觉或默认框架的工具。
5. `low_frequency_explorer`：低频但适配的探索工具。

## 高频工具反向证明规则

## 使用边界

- taxonomy 是初稿，允许在逐张工具卡转译时小幅修正。
- 修正只能记录当前工具相关调整，不能顺手重排其他工具。
- 如果路由测试发现长期塌缩到高频工具，先记录塌缩，再开后续升级 issue。

# Stanford Vibe Coding Course

把 Stanford CS146S / The Modern Software Developer 课程变成可跟踪的学习系统。

看课程最容易的问题是：当时听懂了，过几天就散了。这个 Skill 把课程材料、笔记、复习、作业和进度追踪组织成一个学习工作流，让 Agent 作为学习教练陪你推进。

## 适合

- 学习 Stanford CS146S / vibe coding / AI-assisted software development
- 用 Obsidian 管理课程笔记和复习
- 让 Agent 帮你解释概念、安排进度、检查作业
- 把课程学习变成可持续输出的系统

## 它会做什么

- 读取课程材料和翻译内容
- 创建结构化学习笔记
- 解释关键概念和技术背景
- 跟踪学习进度
- 安排主动回忆和间隔复习
- 辅助完成作业和复盘

## 怎么触发

```text
开始学习 CS146S
继续 Stanford vibe coding 课程
解释这一周课程
帮我复习这节课
检查我的课程作业
```

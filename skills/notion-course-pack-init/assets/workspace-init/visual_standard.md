# Notion Course Pack 页面标准

## 首屏

- 第一屏必须让用户看到下一步动作和关键导航。
- Course Home 把 Runtime Index 与继续上课命令放在长说明之前。
- Runtime Snapshot 把当前节点和下一讲入口放在最上方。

## 结构

- 关键状态必须写成文字，不能只依赖颜色或图标。
- 关键链接使用明确名称，不使用“点这里”。
- 不把运行信息藏进图片、复杂分栏或多层折叠。
- 手机端不依赖多栏布局。

## 颜色

- 绿色：可用、进行中、已完成。
- 黄色：待确认、待测试、需要关注。
- 红色：阻塞、失败、禁止继续。
- 蓝色：说明、协议、普通信息。
- 灰色：未知、归档、停用。

## 页面职责

每个页面只承担自己的职责。Course_Map 不写成长课文，Sessions 不存完整聊天记录，Notes Inbox 不冒充已确认的 Obsidian 笔记，Codex Handoff Queue 不收普通旁支问题。

## 可读取性

ChatGPT 在看不到视觉设计时仍应理解页面：标题、字段名、链接和状态都必须在正文中明确出现。

# Course Pack 模板库

本页说明正式课程的固定页面职责。模板由 Codex 读取 Skill 中的 `assets/templates/` 后生成，不在 Notion 中手工复制。

## 每门课程的 8 个页面

1. Course Home：课程入口、范围、Runtime Index 与继续上课命令。
2. Runtime Snapshot：当前节点、下一讲入口和最近状态。
3. Course_Map：来源能力架构与个性化学习路线。
4. Course_State & Profile：进度证据与稳定学习画像。
5. Sources & Coverage：材料范围、完整读取状态和双向映射。
6. Sessions：每讲的推进问题、判断、讲解和结果。
7. Notes Inbox：按稳定知识对象组织的候选笔记。
8. Codex Handoff Queue：结构、权限、材料和修复事项。

## 创建新课程

在 Codex 中提供：

- 本工作区首页 URL；
- 课程名称；
- 要纳入正式范围的完整材料；
- 已知的学习目标、用途或起点。

Codex 会完整读取材料，再用一至三个问题完成路线校准。校准完成前不会创建生产 Course Pack。

## 更新边界

Codex 只替换每页的托管区域，保留托管区域外的用户内容。ChatGPT 日常上课只更新四个运行页，不改课程地图与来源覆盖页。

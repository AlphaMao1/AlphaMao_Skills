# 选座理论与降级

## 决策顺序

1. 确认银幕方向、影厅和场次。
2. 排除遮挡、极端偏轴、无障碍保留位、过道缺口和已知故障区。
3. 评估视觉几何。
4. 靠近声场中轴与可确认的中央聆听区域。
5. 按沉浸、舒适、字幕、眩晕和多人连座调整。
6. 最后才考虑当前余座；没有实时截图就不给具体可售座号。

## 几何计算

已知银幕宽度 `W`、眼睛到银幕距离 `D`、横向偏移 `X` 和银幕上沿相对眼高 `H` 时：

```text
水平视角 = 2 × atan(W / (2D))
横向偏轴角 = atan(X / D)
上沿仰角 = atan(H / D)
```

使用 `scripts/decision_support.py seat` 计算，保存输入来源。尺寸来自社区估算时，结果仍是估算。

THX 曾给影院设计者以最远座约 36° 水平视角作为认证银幕布置参考；它是设计参考，不是所有影片、银幕和用户的唯一最佳座位：[THX screen placement](https://www.thx.com/questions/thx-certified-screen-placement/)。不要把某个历史角度或“全厅三分之二排”写成普适硬标准。

## 声音

优先影厅横向中轴。Dolby Atmos 影院规范以参考聆听位（RLP）为中心定义中央聆听区域（CLA），典型 CLA 宽度为影厅宽度的三分之一、长度为首末排距离的三分之一：[Dolby Atmos Specifications](https://professional.dolby.com/siteassets/cinema/dolby-audio-products/dolby-atmos-specifications.pdf)。

这用于说明“中央区域通常更稳”，不是从座位图自动推断真实 RLP。没有影厅设计或校准资料时，不声称某一排就是声学甜点。

## 无截图输出

### 有尺寸与距离

计算多个候选排的视角、仰角和偏轴，结合用户偏好给：

- **平衡首选区**：中轴附近，沉浸与仰视均不过度。
- **更沉浸区**：在用户舒适边界内前移，接受更大视角。
- **更舒适区**：后移并降低仰视，长片、字幕敏感或易眩晕优先。
- **避开区**：明显偏轴、遮挡、过近仰视、破坏声像的边缘或已知故障位。

### 只有座位图或总排数

先找中轴、过道、前后区和特殊座。可用“前段／中段／后段 + 中间若干座”的区域表达；必要时把全厅前后位置的约 35%—55% 作为沉浸探索区、50%—70% 作为平衡起点、65%—80% 作为舒适起点。这些只是无几何数据时的可调启发式，影厅坡度、银幕高度、实际声场或用户经验优先。

### 数据很少

只给方向：横向靠中、避免最前和极端边侧；要求用户在购票页按区域选择。不精确到排号和座号。

## 截图增强

用户自愿提供猫眼、淘票票或影院购票页截图后：

1. 先确认截图对应的影片、影院、影厅、日期和场次；缺失时明确限制。
2. 识别银幕方向、排／列／座号、已售／不可售／可售、过道、情侣座、无障碍位和明显特殊区。
3. 对可见余座给当前首选、前一／后一排备选和多人连续座备选。
4. 标注截图核查时间与图像置信度，不承诺余座保持不变。

截图裁切、模糊、颜色图例缺失或状态相近时，先写无法读取的部分，再退回区域建议；不得猜已售状态。不要替用户点击或锁座。

## 偏好修正

- 沉浸优先：在视线和眩晕边界内前移。
- 舒适／长片／字幕敏感：后移，降低仰视和频繁眼动。
- 声音优先：尽量保持横向中轴，并靠近可确认的 CLA／RLP 周边。
- 易眩晕：避免过近、动感座椅、喷水和强 3D。
- 多人连座：先保证连续，再说明相对中轴或理想排位的损失。
- 儿童、身高或无障碍需求：以安全、视线和影院规则为先，不套用普通成人模型。

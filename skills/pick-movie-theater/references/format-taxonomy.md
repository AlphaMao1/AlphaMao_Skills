# 高级影厅格式分类与普通用户选择

维护核查日期：2026-07-29。这里定义候选分类、购票标签翻译和防误判规则；具体影院与影片必须重新搜索当前来源。

## 通用拆解

不要问“真不真”，先分别回答：

1. 影片是否为该格式制作、重制或发行。
2. 当前地区是否拿到该版本。
3. 具体影厅的投影、银幕、声音和认证能力是什么。
4. 当前场次是否明确使用该版本和该影厅。

品牌或营销名称只证明名称存在，不能替代以上四项。

面向普通用户时，不只报告设备名。每个候选至少翻译成：

> 购票标签是什么；它实际保证什么；没有保证什么；本片多得到什么；与同品牌其他厅相比为什么选它。

## 跨格式快速选择表

这张表只负责把票务标签翻译成候选方向，不能代替逐厅核验：

| 格式家族 | 通常追求什么 | 选择前必须确认 |
| --- | --- | --- |
| IMAX | 专用画幅、IMAX母版、大银幕和统一放映体系 | 具体代际、1.43／1.90片源、银幕比例、声音代际 |
| Dolby Cinema／杜比影院 | 黑位、对比度、HDR画面和Atmos整体体验 | 是否官方Dolby Cinema、本片Vision／Atmos版本、银幕与遮幅 |
| CINITY投影厅 | 4K、高亮、HDR、HFR、广色域等组合能力 | 本片实际取得哪些能力，不把120fps硬件上限当成片源 |
| CINITY LED／其他影院LED | 自发光黑位、亮度、对比度、锐度 | 屏幕尺寸、透声方案、DCI认证、本片版本和声场 |
| CGS／中国巨幕 | 大银幕、国产PLF母版和多种设备组合 | 认证代际、投影机、银幕、声音和本片专用母版 |
| ScreenX／侧幕格式 | 专用侧画面和包围视野 | 是否有本片专用内容、覆盖时长、中心画面质量 |
| 4DX／MX4D／D-BOX／ICE | 动感座椅、风水气味或环境光效 | 本片效果编码、刺激强度、用户耐受；不把体感当画质 |
| LUXE／院线自有PLF／激光巨幕 | 大屏、激光或院线自定义综合方案 | 名称不统一，必须逐项核验投影、银幕、声音和校准 |
| Atmos／DTS:X／THX等声音型厅 | 沉浸声、声学设计或认证 | 本片原生音轨、具体扬声器与厅体；声音标签不证明画面 |

跨格式选择顺序统一为：先找本片独占内容，再看具体厅能否呈现，然后比较画面、声音、厅体几何和维护，最后加入交通、价格和个人耐受。任何品牌都不能跳过这条链。

## IMAX

影片端分开记录 `Filmed for IMAX`、IMAX DMR、1.90:1／1.43:1 扩展画幅、扩画时长、专用声音和 IMAX 70mm 胶片拷贝。IMAX 官方说明 `Filmed for IMAX` 会在创作到后期阶段合作，并可能采用 1.90:1 或 1.43:1；这不表示每部相关影片都有 1.43:1 或胶片版：[IMAX 官方说明](https://www.imax.com/filmed-for-imax)。

影厅端至少区分以下类型。先确认类型，再比较银幕、画幅、声音、维护和场次：

| 购票或社区标签 | 实际应核验 | 对普通用户意味着什么 |
| --- | --- | --- |
| IMAX 70mm／15/70 | 胶片放映机、影片胶片拷贝、当前胶片场次 | 稀缺胶片版本；有设备不等于本片有拷贝 |
| GT 激光 | 双 4K 系统、银幕是否为 1.43、影片是否有当地 1.43 版本 | 只有“1.43银幕 + 1.43片源 + 对应场次”同时成立，才获得完整1.43画面 |
| Commercial Laser／CoLa | 具体投影系统、最大画幅、银幕尺寸、12声道与否 | 通常是高规格4K激光IMAX候选，但不能只凭开业年份或银幕大小定型 |
| Laser XT | 具体代际、最大画幅、银幕尺寸、6／12声道 | 也是4K激光IMAX，但常用于更灵活的中小型厅；不能仅凭“新”判定胜过CoLa |
| 氙灯数字 IMAX | 双机2K、灯泡和维护状态、银幕比例、声音代际 | 仍可能有IMAX专用画幅，但画面亮度、解析力和维护风险通常更值得复核 |
| “激光IMAX／IMAX with Laser” | CoLa、XT、GT中的哪一种 | 这是上位标签，不足以直接比较两家影院 |

“IMAX 上映”不等于 `Filmed for IMAX`；1.43 银幕不等于当前场次有 1.43 内容；影厅能放胶片不等于该片有胶片拷贝。

普通用户选择顺序：

1. 先看本片在当地有没有 1.43、1.90、胶片或专用声音增量。
2. 有 1.43 时优先匹配可实际呈现 1.43 的 GT 厅；没有时不要为高银幕空白区域付费。
3. 都是 1.90 时，再比较 CoLa／XT、银幕尺寸、声音代际、维护和座位几何。
4. 本片没有 IMAX 独占画面时，把 Dolby Cinema、CINITY LED 和其他高画质厅放回同一层比较。

## Dolby

至少分成：

| 购票标签 | 实际保证或线索 | 不自动保证 |
| --- | --- | --- |
| Dolby Cinema／杜比影院 | 完整品牌方案；核实官方认证。Dolby 将其描述为 Dolby Vision 双 4K 激光、Dolby Atmos 和整体影厅设计的组合：[Dolby Cinema](https://www.dolby.com/experience/cinema/) | 不保证本片一定有 Atmos 原生混音，也不保证银幕比例和本片画幅天然匹配 |
| Dolby Vision + Dolby Atmos 高级厅 | 同时出现两项能力时继续核实授权、投影和厅级方案 | 不因两个词同时出现就升级为 Dolby Cinema |
| Dolby Atmos 厅／杜比全景声厅 | 对象式沉浸音频和头顶扬声器能力：[Dolby Atmos 影院说明](https://professional.dolby.com/cinema/dolby-atmos/) | 不保证 Dolby Vision、双 4K、HDR、巨幕或本片有 Atmos 音轨 |
| 杜比 7.1 | 声道式音频播放能力 | 不是 Atmos，不证明画面系统或高级影厅认证 |
| “杜比厅／杜比全景声巨幕” | 营销名称或声音能力线索 | 不证明是 Dolby Cinema，也不证明银幕和投影规格 |

比较多个“杜比”候选时，按以下顺序回答：

1. 哪个是官方 Dolby Cinema，哪些只是 Atmos 或 Dolby 7.1。
2. 本片是否有 Dolby Vision／Atmos 对应版本或音轨。
3. 当前 DCP 画幅与银幕原生比例是否匹配。
4. 是固定宽银幕、固定平幕，还是有可变遮幅；可变遮幅能否覆盖本场比例。
5. 银幕大小、座位视角、近期校准和故障口碑是否足以改变选择。

“遮幅杜比”是歧义词。必须区分“影片使用2.39遮幅构图”和“影厅具有可变遮幅幕布”；只有记录 `DCP画幅 + 银幕比例 + 遮幅位置 + 实际呈现方式` 后才能判断。

## CINITY 与 CGS 中国巨幕

- CINITY：分别核实影片是否有专用 4K、HFR、HDR、WCG、高亮或 3D 版本，以及具体厅当前系统能力。系统支持最高 4K／120fps 不表示每部影片都获得该版本：[CINITY 官方技术页](https://cinity.com/)。
- CINITY LED：作为独立候选家族搜索，核实直显屏型号、尺寸、DCI 认证、2D／3D亮度、透声方案和当前影片版本。硬件支持4K／120fps不表示本片是HFR。
- CGS 中国巨幕：核实认证、投影设备与代际、声音、银幕、专用母版和当前场次。只出现“中国巨幕”字样时，不推断设备或母版。

## 侧幕、动感与环境效果

- ScreenX：核实影片是否有专门侧墙内容、覆盖时长，以及是普通后期扩展还是制作阶段参与的 `Shot for SCREENX`；没有专用内容时，三面银幕硬件本身不产生同等增量。
- 4DX／MX4D：把动感、风、水、气味等当作体验偏好，不自动视为更高画质或声音。先检查影片效果版本、当前场次和用户对眩晕、喷水、强刺激的限制。
- ULTRA 4DX：分别核验 ScreenX 侧幕内容和4DX环境效果；组合品牌不保证两部分都对本片有专用增量。
- ICE Immersive：核实侧墙灯光／画面扩展方式和本片专用内容，不把环境光效当作更高中心画质。
- D-BOX及其他动感座椅：核实本片动作编码、座椅覆盖范围和用户耐受；它们主要改变体感，不自动提高主画面或声音规格。

## LED 与普通激光巨幕

- LED 直显／Samsung Onyx／HeyLED 等：核实具体系统、DCI 认证、分辨率、亮度、银幕尺寸、透声或扬声器布置和本片版本；不要把家用显示技术参数套用到影院。
- “激光巨幕”“LUXE”“VIP 巨幕”等非统一名称：记录投影机、光源、分辨率、机型数量、银幕尺寸／比例、声场和校准证据。字段不足时只能作为候选，不能因名称中有“激光”或“巨幕”直接晋级。
- 纯声音候选：把 DTS:X、THX、Atmos 等作为声音能力搜索入口，但仍需核对具体厅、影片原生音轨和画面系统。

## 决策输出

对每个格式写成“能力 + 本片增量 + 当前场次 + 代价”：

> 某厅已确认具备什么；本片在本地区已确认取得什么；当前场次能否把两者接上；相比备选多得到什么以及仍未知什么。

当同城出现多个 IMAX 或多个“杜比”厅时，必须额外给一张普通用户差异表，至少包含：`购票标签`、`具体类型`、`本片画幅／音轨增量`、`银幕与遮幅匹配`、`为什么选／不选`。不要求用户先理解 CoLa、XT、Atmos 等术语。

不要输出一个脱离影片、地区和场次的永久格式排行榜。
